# Explicación Detallada y Completa de `nueva_venta.php`

Este archivo es el **módulo de creación de ventas** del sistema del *Taller de Pachi*. 

Es uno de los archivos más completos e importantes del sistema, ya que combina tres capas de programación:
1. **PHP (Servidor):** Procesa el guardado en la base de datos mediante transacciones seguras, calcula el total y descuenta automáticamente los productos del inventario (stock).
2. **HTML5 y Bootstrap 5 (Diseño):** Presenta una interfaz organizada en dos secciones (cabecera con cliente/vendedor y detalle con selector de artículos).
3. **JavaScript (Navegador):** Permite agregar productos de forma dinámica a una tabla en tiempo real, cargar precios automáticamente, quitar productos y calcular subtotales y totales sin necesidad de recargar la página.

---

## SECCIÓN 1: Código PHP (Lógica del Servidor)

El archivo comienza ejecutando código en el servidor antes de mostrar cualquier elemento visual.

### 1. Inclusión de Módulos Base
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`verificarsesion.php`**: Verifica que el usuario tenga una sesión abierta. Si no está logueado, lo expulsa al login de inmediato.
* **`config/conexion.php`**: Conecta a la base de datos MySQL con PDO mediante la variable `$conexion`.
* **`require_once`**: Garantiza que estos archivos se incluyan una sola vez de forma obligatoria.

---

### 2. Procesamiento del Formulario al Guardar la Venta (`POST`)
```php
$error = "";
if ($_SERVER["REQUEST_METHOD"] == "POST") {
```
* **`$error = ""`**: Variable inicializada en vacío para guardar cualquier mensaje de error que pueda ocurrir.
* **`if ($_SERVER["REQUEST_METHOD"] == "POST")`**: Comprueba si el usuario presionó el botón final "Guardar Venta".

---

### 3. Captura y Limpieza de los Datos Enviados
```php
    $id_cliente = intval($_POST["id_cliente"] ?? 0);
    $id_usuario = $_SESSION["id_usuario"];
    $productos_ids = $_POST["id_producto"] ?? [];
    $cantidades = $_POST["cantidad"] ?? [];
    $precios = $_POST["precio"] ?? [];
```
* **`$id_cliente`**: Recibe el ID del cliente seleccionado y lo transforma a entero con `intval()` para evitar inyecciones.
* **`$id_usuario`**: Obtiene el ID del vendedor directamente de la sesión (`$_SESSION`), evitando que el usuario pueda falsificar quién atendió la venta.
* **`$productos_ids`**: Arreglo con los IDs de todos los productos agregados a la lista.
* **`$cantidades`**: Arreglo con las cantidades compradas de cada producto.
* **`$precios`**: Arreglo con el precio unitario pactado para cada producto.
* **`?? []` / `?? 0`**: Operadores de seguridad por si algún dato no fue enviado.

---

### 4. Validación de Datos en el Servidor
```php
    if ($id_cliente <= 0 || count($productos_ids) == 0) {
        $error = "Debés seleccionar un cliente y agregar al menos un producto.";
    } else {
```
* Comprueba dos reglas esenciales del negocio:
  * Que se haya elegido un cliente válido (`$id_cliente > 0`).
  * Que la venta tenga al menos un producto cargado (`count($productos_ids) > 0`).
* Si alguna regla no se cumple, llena la variable `$error` y no guarda nada.

---

### 5. Cálculo del Total de la Venta en el Servidor
```php
        $total_venta = 0;
        for ($i = 0; $i < count($productos_ids); $i++) {
            $total_venta += intval($cantidades[$i]) * floatval($precios[$i]);
        }
```
* Realiza una suma acumulativa en el servidor recorriendo los productos con un ciclo `for`.
* Multiplica la cantidad entera (`intval`) por el precio decimal (`floatval`) de cada producto.
* **¿Por qué se hace en el servidor si JavaScript ya calculó el total?** Por seguridad. Nunca se debe confiar ciegamente en los valores calculados en el navegador del cliente, ya que podrían ser alterados antes del envío.

---

### 6. Transacción en Base de Datos (Guardado Seguro y Descuento de Stock)
```php
        $conexion->beginTransaction();
        try {
```
* **`$conexion->beginTransaction()`**: Inicia una transacción. Le ordena a MySQL que todas las operaciones siguientes se ejecuten en bloque como una unidad indivisible.

#### A. Guardar la Cabecera de la Venta
```php
            $stmt_cab = $conexion->prepare("INSERT INTO ventas (id_cliente, id_usuario, total) VALUES (?, ?, ?)");
            $stmt_cab->execute([$id_cliente, $id_usuario, $total_venta]);
            $id_venta = $conexion->lastInsertId();
```
* Inserta el registro principal en la tabla `ventas` con el cliente, el vendedor y el monto total.
* **`$conexion->lastInsertId()`**: Función clave de PDO que recupera el número exacto de ID autoincremental que la base de datos le asignó a esta nueva venta (por ejemplo, la venta número 24).

#### B. Guardar los Detalles y Descontar el Stock
```php
            $stmt_det = $conexion->prepare("INSERT INTO detalle_ventas (id_venta, id_producto, cantidad, precio_unitario, subtotal) VALUES (?, ?, ?, ?, ?)");
            $stmt_stock = $conexion->prepare("UPDATE productos SET stock = stock - ? WHERE id_producto = ?");
            for ($i = 0; $i < count($productos_ids); $i++) {
                $id_prod = intval($productos_ids[$i]);
                $cant = intval($cantidades[$i]);
                $prec = floatval($precios[$i]);
                $sub = $cant * $prec;
                $stmt_det->execute([$id_venta, $id_prod, $cant, $prec, $sub]);
                $stmt_stock->execute([$cant, $id_prod]);
            }
```
* Prepara dos consultas reutilizables:
  1. Para insertar cada renglón en `detalle_ventas` vinculándolo con `$id_venta`.
  2. Para restar del stock en la tabla `productos` (`stock = stock - ?`).
* Recorre cada producto vendido:
  * Inserta el detalle con ID de venta, ID de producto, cantidad, precio y subtotal.
  * Ejecuta la resta en el inventario restando la cantidad vendida.

#### C. Confirmación o Cancelación (Commit / Rollback)
```php
            $conexion->commit();
            header("Location: ver_venta.php?id=" . $id_venta);
            exit();
        } catch (Exception $e) {
            $conexion->rollBack();
            $error = "Ocurrió un error al guardar la venta.";
        }
```
* **`$conexion->commit()`**: Hace permanentes y definitivos todos los cambios en la base de datos.
* **`header(...)` y `exit()`**: Redirige al usuario a la vista de comprobante o detalle (`ver_venta.php`) con el ID generado.
* **`catch` y `$conexion->rollBack()`**: Si ocurre una falla en cualquier paso (por ejemplo, corte de luz o error de base de datos), desase todos los cambios por completo y muestra el aviso de error.

### 7. Consultas Auxiliares para Llenar los Selectores del Formulario

* Carga de la base de datos la lista de todos los clientes (ordenados por nombre) para ponerlos en un menú desplegable.
* Carga la lista de productos con su precio y stock disponible para el selector de artículos.

## SECCIÓN 3: Código JavaScript (Interactividad en el Navegador)

Este bloque de script corre dentro del navegador del usuario sin consultar al servidor en cada clic.

### 1. Función `cargarPrecio()`
```javascript
function cargarPrecio() {
    let select = document.getElementById("selectProducto");
    let opcion = select.options[select.selectedIndex];
    document.getElementById("inputPrecio").value = opcion.getAttribute("data-precio");
}
```
* **¿Qué hace?** Lee qué producto eligió el usuario en el desplegable, busca su atributo `data-precio` y escribe ese valor dentro de la casilla de texto de precio unitario.

---

### 2. Función `agregarProducto()`
```javascript
function agregarProducto() {
    let select = document.getElementById("selectProducto");
    let idProducto = select.value;
    let nombreProducto = select.options[select.selectedIndex].text;
    let cantidad = parseInt(document.getElementById("inputCantidad").value);
    let precio = parseFloat(document.getElementById("inputPrecio").value);
    if (idProducto === "" || cantidad <= 0 || isNaN(precio)) {
        alert("Seleccioná un producto, cantidad válida y precio.");
        return;
    }
```
* Lee los valores ingresados (ID del producto, texto del nombre, cantidad convertida a entero con `parseInt` y precio convertido a decimal con `parseFloat`).
* Valida que no se intente agregar un producto en blanco, cantidades en cero/negativas o precios inválidos. Si algo está mal, muestra una alerta y se detiene con `return`.

#### Inserción de la Fila con Inputs Ocultos
```javascript
    let subtotal = cantidad * precio;
    let tbody = document.getElementById("tablaDetalle");
    let fila = document.createElement("tr");
    fila.innerHTML = `
        <td>${nombreProducto}<input type="hidden" name="id_producto[]" value="${idProducto}"></td>
        <td>${cantidad}<input type="hidden" name="cantidad[]" value="${cantidad}"></td>
        <td>$${precio.toFixed(2)}<input type="hidden" name="precio[]" value="${precio}"></td>
        <td class="subtotal-celda" data-subtotal="${subtotal}">$${subtotal.toFixed(2)}</td>
        <td><button type="button" class="btn btn-danger btn-sm" onclick="eliminarFila(this)">Quitar</button></td>
    `;
    tbody.appendChild(fila);
```
* Calcula el subtotal multiplicando cantidad por precio.
* Crea un elemento de fila de tabla (`<tr>`).
* **Concepto Clave (`input type="hidden"` con corchetes `[]`):**
  * Para que PHP pueda recibir la lista completa de productos al enviar el formulario, cada fila agrega campos ocultos con el nombre terminado en corchetes: `name="id_producto[]"`, `name="cantidad[]"` y `name="precio[]"`.
  * Los corchetes le indican a PHP que empaquete todos esos datos en un **arreglo (array)** ordenado.
* Agrega un botón rojo "Quitar" con el evento `onclick="eliminarFila(this)"`.
* Agrega la fila al cuerpo de la tabla (`tbody.appendChild(fila)`).

#### Limpieza de los Campos de Entrada
```javascript
    calcularTotal();
    select.value = "";
    document.getElementById("inputCantidad").value = 1;
    document.getElementById("inputPrecio").value = 0;
}
```
* Llama a `calcularTotal()` para refrescar el monto acumulado.
* Restablece los campos de entrada para que el usuario pueda cargar el siguiente producto cómodamente.

---

### 3. Función `eliminarFila(boton)`
```javascript
function eliminarFila(boton) {
    boton.closest("tr").remove();
    calcularTotal();
}
```
* Recibe el botón sobre el cual se hizo clic.
* **`boton.closest("tr")`**: Busca la fila `<tr>` padre exacta donde se encuentra ese botón.
* **`.remove()`**: Elimina toda esa fila del documento web.
* Vuelve a llamar a `calcularTotal()` para descontar el subtotal de ese producto eliminado.

---

### 4. Función `calcularTotal()`
```javascript
function calcularTotal() {
    let celdas = document.querySelectorAll(".subtotal-celda");
    let total = 0;
    celdas.forEach(function(celda) {
        total += parseFloat(celda.getAttribute("data-subtotal"));
    });
    document.getElementById("totalTexto").innerText = total.toFixed(2);
}
```
* Busca todas las celdas que tengan la clase `.subtotal-celda`.
* Recorre cada una con un ciclo `forEach` y va sumando los valores guardados en su atributo `data-subtotal`.
* **`.toFixed(2)`**: Da formato al total final con dos cifras decimales.
* Escribe el total final dentro del elemento con identificador `totalTexto`.
