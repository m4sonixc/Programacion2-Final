# Explicación Exhaustiva y Completa de `clientes.php`

Este archivo es el **módulo integral de gestión de clientes** del sistema del *Taller de Pachi*. 

Implementa un **CRUD completo** (Crear, Leer, Actualizar y Eliminar) dentro de una **misma pantalla de doble columna**:
1. **Listar:** Muestra la lista de todos los clientes registrados en una tabla responsiva.
2. **Crear:** Permite dar de alta a un nuevo cliente con sus datos de contacto.
3. **Editar:** Carga los datos de un cliente existente en el formulario para modificarlos sin salir de la página.
4. **Eliminar:** Borra a un cliente de forma segura, impidiendo la eliminación si el cliente ya tiene ventas asociadas en el taller para no corromper el historial comercial.

---

## BLOQUE 1: Código PHP (Lógica del Servidor y Base de Datos)

Todo el código contenido entre `<?php` y `?>` se ejecuta en el servidor antes de generar la respuesta visual que ve el usuario.

### 1. Inclusión de Archivos y Seguridad
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Invoca el control de acceso. Si el usuario no ha iniciado sesión, este archivo lo expulsa automáticamente hacia `login.php`. `require_once` garantiza que el archivo se cargue una sola vez y frena la ejecución si el archivo no existe.
* **`require_once "config/conexion.php";`**: Carga el objeto de conexión a la base de datos MySQL (`$conexion`) mediante la interfaz moderna PDO.

---

### 2. Inicialización de Variables de Estado
```php
$mensaje = "";
$tipo_alerta = "";
$id_editar = "";
$nombre_editar = "";
$apellido_editar = "";
$telefono_editar = "";
$email_editar = "";
$direccion_editar = "";
```
* **`$mensaje = "";`**: Cadena de texto vacía donde se guardará el mensaje informativo o de error que se le mostrará al usuario en pantalla.
* **`$tipo_alerta = "";`**: Guardará la clase de estilo visual de Bootstrap para el mensaje (`"success"` para color verde o `"danger"` para color rojo).
* **`$id_editar = "";`**: Almacena el ID del cliente que se quiere modificar. Si está vacío, el sistema sabe que el formulario se utilizará para registrar un cliente nuevo; si contiene un número, se usará para actualizarlo.
* **`$nombre_editar`, `$apellido_editar`, `$telefono_editar`, `$email_editar`, `$direccion_editar`**: Variables inicializadas en vacío que servirán para rellenar automáticamente los campos del formulario cuando el usuario decida editar un cliente.

---

### 3. Operación de Eliminación (`GET["eliminar"]`)
Se ejecuta cuando en la dirección URL viene el parámetro `eliminar` (por ejemplo: `clientes.php?eliminar=7`).

```php
if (isset($_GET["eliminar"])) {
    $id = intval($_GET["eliminar"]);
    try {
        $stmt = $conexion->prepare("DELETE FROM clientes WHERE id_cliente = ?");
        $stmt->execute([$id]);

        $mensaje = "Cliente eliminado correctamente.";
        $tipo_alerta = "success";
    } catch (PDOException $e) {
        $mensaje = "No se puede eliminar el cliente porque tiene ventas registradas.";
        $tipo_alerta = "danger";
    }
}
```
* **`if (isset($_GET["eliminar"]))`**: Evalúa si se hizo clic en el botón de eliminar de algún cliente.
* **`intval($_GET["eliminar"])`**: Convierte el dato recibido de la URL estrictamente a un número entero. Esto actúa como un escudo de seguridad contra inyecciones SQL u otros valores maliciosos.
* **`try { ... } catch (PDOException $e) { ... }`**: Control de integridad referencial de base de datos.
  * La tabla `ventas` tiene una clave foránea (*Foreign Key*) que apunta a la tabla `clientes` (`id_cliente`).
  * Si intentamos borrar a un cliente que ya tiene compras o facturas cargadas en el taller, MySQL arrojará un error de restricción de clave foránea.
  * El bloque `catch` atrapa esa excepción técnica e impide que la aplicación se caiga o muestre un error incomprensible, mostrando en su lugar el mensaje en rojo: *"No se puede eliminar el cliente porque tiene ventas registradas."* (`danger`).
  * Si el cliente no tiene ninguna venta en su historial, se borra limpiamente y se muestra el mensaje en verde: *"Cliente eliminado correctamente."* (`success`).

---

### 4. Carga de Datos para Edición (`GET["editar"]`)
Se activa cuando el usuario hace clic en el botón amarillo "Editar" de alguna fila (por ejemplo: `clientes.php?editar=5`).

```php
if (isset($_GET["editar"])) {
    $id_editar = intval($_GET["editar"]);
    $stmt = $conexion->prepare("SELECT * FROM clientes WHERE id_cliente = ?");
    $stmt->execute([$id_editar]);
    if ($fila = $stmt->fetch()) {
        $nombre_editar = $fila["nombre"];
        $apellido_editar = $fila["apellido"];
        $telefono_editar = $fila["telefono"];
        $email_editar = $fila["email"];
        $direccion_editar = $fila["direccion"];
    }
}
```
* **`intval($_GET["editar"])`**: Sanitiza el ID recibido por URL como un número entero.
* **`SELECT * FROM clientes WHERE id_cliente = ?`**: Busca en la base de datos la fila del cliente correspondiente a ese identificador.
* **`if ($fila = $stmt->fetch())`**: Si el cliente existe, extrae cada uno de sus datos personales y de contacto y los asigna a las variables `$nombre_editar`, `$apellido_editar`, `$telefono_editar`, `$email_editar` y `$direccion_editar` para que aparezcan escritos en el formulario.

---

### 5. Procesamiento del Formulario: Crear o Actualizar (`POST`)
Se ejecuta cuando el usuario presiona el botón principal del formulario para enviar datos.

```php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $id_cliente = $_POST["id_cliente"] ?? "";
    $nombre = trim($_POST["nombre"] ?? "");
    $apellido = trim($_POST["apellido"] ?? "");
    $telefono = trim($_POST["telefono"] ?? "");
    $email = trim($_POST["email"] ?? "");
    $direccion = trim($_POST["direccion"] ?? "");
```
* **`$_SERVER["REQUEST_METHOD"] == "POST"`**: Comprueba que la petición fue enviada mediante el método POST del formulario.
* **`$id_cliente`**: Rescata el ID del campo oculto. Si está vacío, el usuario está agregando; si contiene un ID, está editando.
* **`trim(...)`**: Remueve espacios en blanco innecesarios al comienzo y al final de cada texto ingresado.
* **`?? ""`**: Operador de fusión por nulo que asigna una cadena vacía en caso de que algún campo no haya sido enviado.

#### Validación y Decisión (Insertar o Modificar)
```php
    if ($nombre == "" || $apellido == "") {
        $mensaje = "Nombre y apellido son obligatorios.";
        $tipo_alerta = "danger";
    } else {
        if ($id_cliente == "") {
            $stmt = $conexion->prepare("INSERT INTO clientes (nombre, apellido, telefono, email, direccion) VALUES (?, ?, ?, ?, ?)");
            $stmt->execute([$nombre, $apellido, $telefono, $email, $direccion]);
            $mensaje = "Cliente agregado correctamente.";
        } else {
            $stmt = $conexion->prepare("UPDATE clientes SET nombre = ?, apellido = ?, telefono = ?, email = ?, direccion = ? WHERE id_cliente = ?");
            $stmt->execute([$nombre, $apellido, $telefono, $email, $direccion, $id_cliente]);
            $mensaje = "Cliente actualizado correctamente.";
        }
        $tipo_alerta = "success";
    }
}
```
* **Validación de campos obligatorios:** Si el nombre o el apellido están vacíos (`$nombre == "" || $apellido == ""`), interrumpe la operación y carga un mensaje de error en rojo (`danger`).
* **Si la validación es correcta:**
  * **Caso 1: Creación (`$id_cliente == ""`):** Como el campo oculto no tiene ID, ejecuta una sentencia `INSERT INTO` en la tabla `clientes` guardando los 5 datos. Muestra el mensaje: *"Cliente agregado correctamente."*
  * **Caso 2: Modificación (`else`):** Como el campo oculto sí trae un ID, ejecuta una sentencia `UPDATE clientes SET ... WHERE id_cliente = ?` actualizando los datos de ese cliente específico. Muestra el mensaje: *"Cliente actualizado correctamente."*
* En ambos casos exitosos, se define `$tipo_alerta = "success"`.

---

### 6. Consulta para el Listado General de Clientes
```php
$clientes = $conexion->query("SELECT * FROM clientes ORDER BY id_cliente DESC")->fetchAll();
```
* Realiza una consulta directa a la tabla `clientes`.
* **`ORDER BY id_cliente DESC`**: Ordena los registros de manera descendente, haciendo que el último cliente registrado aparezca siempre primero en la tabla.
* **`fetchAll()`**: Devuelve todos los clientes encontrados como un arreglo de datos asociativo y los almacena en la variable `$clientes`.

## BLOQUE 2: Código HTML y Bootstrap (Interfaz Gráfica)

### 1. Cabecera del Documento y Hoja de Estilos
```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Clientes - Taller de Pachi</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
```
* **`<!DOCTYPE html>`** y **`<html lang="es">`**: Estructura de documento estándar HTML5 en idioma español.
* **`charset="UTF-8"`**: Soporte para caracteres latinos, tildes y letra ñ.
* **`viewport`**: Asegura que la página sea responsiva y se ajuste a teléfonos móviles, tablets y computadoras.
* **`link` de Bootstrap 5**: Carga los estilos visuales de Bootstrap desde su servidor CDN oficial.

---

### 2. Estructura del Cuerpo, Barra de Navegación y Título
```html
<body class="bg-light">
    <?php include "navbar.php"; ?>
    <div class="container">
        <h3 class="mb-4">Gestión de Clientes</h3>
```
* **`class="bg-light"`**: Pinta el fondo de la pantalla de color gris claro.
* **`<?php include "navbar.php"; ?>`**: Incluye de forma modular el menú de navegación superior del sistema.
* **`container`**: Centra los componentes con márgenes simétricos a los lados.
* **`<h3 class="mb-4">`**: Título de la sección con un margen inferior de nivel 4.

### 3. Mensaje Dinámico de Alerta
```php
        <?php if ($mensaje != ""): ?>
            <div class="alert alert-<?php echo $tipo_alerta; ?> alert-dismissible fade show">
                <?php echo $mensaje; ?>
                <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
            </div>
        <?php endif; ?>
```
* **`if ($mensaje != "")`**: Se imprime únicamente cuando hay una notificación generada por PHP (éxito al guardar, error de validación o restricción al borrar).
* **`alert-<?php echo $tipo_alerta; ?>`**: Asigna dinámicamente la clase de Bootstrap: `alert-success` (fondo verde) o `alert-danger` (fondo rojo).
* **`alert-dismissible fade show`** y **`btn-close`**: Añaden una pequeña "X" a la derecha que permite cerrar la alerta en cualquier momento con una suave animación.

### 5. Columna Izquierda: Formulario Dinámico (`col-md-4`)
Ocupa 4 de las 12 columnas en pantallas medianas o grandes (un tercio del ancho de la pantalla).

```html
            <div class="col-md-4 mb-4">
                <div class="card shadow-sm">
                    <div class="card-header bg-primary text-white">
                        <?php echo ($id_editar != "") ? "Editar Cliente" : "Nuevo Cliente"; ?>
                    </div>
```
* **`card shadow-sm mb-4`**: Tarjeta con bordes redondeados, sombra suave y margen inferior.
* **Cabecera Dinámica (`card-header bg-primary text-white`):**
  * Emplea un operador ternario: `($id_editar != "") ? "Editar Cliente" : "Nuevo Cliente"`.
  * Si `$id_editar` tiene un valor, el título de la tarjeta cambia automáticamente a *"Editar Cliente"*; de lo contrario, muestra *"Nuevo Cliente"*.

#### Campos de Entrada del Formulario
```html
                    <div class="card-body">
                        <form method="POST" action="clientes.php">
                            <input type="hidden" name="id_cliente" value="<?php echo $id_editar; ?>">
```
* **`action="clientes.php"`**: Envía los datos a este mismo archivo mediante el método POST.
* **`<input type="hidden" name="id_cliente"...>`**: Campo oculto que guarda el ID del cliente en edición. Si está vacío, PHP interpretará una inserción; si tiene un ID numérico, interpretará una actualización.

```php
                            <div class="mb-2">
                                <label class="form-label">Nombre</label>
                                <input type="text" name="nombre" class="form-control" required
                                       value="<?php echo htmlspecialchars($nombre_editar); ?>">
                            </div>
                            <div class="mb-2">
                                <label class="form-label">Apellido</label>
                                <input type="text" name="apellido" class="form-control" required
                                       value="<?php echo htmlspecialchars($apellido_editar); ?>">
                            </div>
                            <div class="mb-2">
                                <label class="form-label">Teléfono</label>
                                <input type="text" name="telefono" class="form-control"
                                       value="<?php echo htmlspecialchars($telefono_editar); ?>">
                            </div>
                            <div class="mb-2">
                                <label class="form-label">Email</label>
                                <input type="email" name="email" class="form-control"
                                       value="<?php echo htmlspecialchars($email_editar); ?>">
                            </div>
                            <div class="mb-3">
                                <label class="form-label">Dirección</label>
                                <input type="text" name="direccion" class="form-control"
                                       value="<?php echo htmlspecialchars($direccion_editar); ?>">
                            </div>
```
* **Campo Nombre (`name="nombre"`):** Obligatorio (`required`). Precarga `$nombre_editar` en caso de estar editando.
* **Campo Apellido (`name="apellido"`):** Obligatorio (`required`). Precarga `$apellido_editar`.
* **Campo Teléfono (`name="telefono"`):** Opcional. Precarga `$telefono_editar`.
* **Campo Email (`type="email" name="email"`):** Valida que el texto ingresado tenga formato de correo electrónico (`@` y dominio). Precarga `$email_editar`.
* **Campo Dirección (`name="direccion"`):** Opcional. Precarga `$direccion_editar`.
* **`htmlspecialchars(...)`**: En todos los campos protege los datos contra ataques XSS (Cross-Site Scripting).

#### Botones del Formulario
```php
                            <button type="submit" class="btn btn-primary w-100">
                                <?php echo ($id_editar != "") ? "Guardar Cambios" : "Agregar Cliente"; ?>
                            </button>
                            <?php if ($id_editar != ""): ?>
                                <a href="clientes.php" class="btn btn-secondary w-100 mt-2">Cancelar</a>
                            <?php endif; ?>
                        </form>
                    </div>
                </div>
            </div>
```
* **Botón Principal (`btn-primary w-100`):** Botón azul de ancho completo. Su texto cambia de forma inteligente: muestra *"Guardar Cambios"* si se está editando o *"Agregar Cliente"* si se está creando.
* **Botón Cancelar (`btn-secondary w-100 mt-2`):** Solo se muestra si estamos en modo edición (`$id_editar != ""`). Al presionarlo, recarga `clientes.php` sin parámetros, limpiando todas las casillas y regresando al modo de nuevo cliente.

### 6. Columna Derecha: Tabla de Listado (`col-md-8`)
Ocupa 8 de las 12 columnas en pantallas medianas o grandes (dos tercios del ancho de la pantalla).

```html
            <div class="col-md-8">
                <div class="card shadow-sm">
                    <div class="card-header">Listado de Clientes</div>
                    <div class="card-body p-0 table-responsive">
                        <table class="table table-striped table-hover mb-0">
                            <thead class="table-dark">
                                <tr>
                                    <th>ID</th>
                                    <th>Nombre y Apellido</th>
                                    <th>Teléfono</th>
                                    <th>Email</th>
                                    <th style="width: 150px;">Acciones</th>
                                </tr>
                            </thead>
```
* **`p-0`**: Quita el relleno interno para que la tabla toque los bordes de la tarjeta.
* **`table-responsive`**: Habilita una barra de desplazamiento horizontal automática si la pantalla es muy pequeña (como en un teléfono móvil), evitando que la tabla se deforme.
* **`table-striped table-hover mb-0`**: Filas con colores alternados, efecto visual al pasar el cursor por encima y sin margen inferior sobrante.
* **`thead class="table-dark"`**: Cabecera oscura con las columnas correspondientes: ID, Nombre y Apellido, Teléfono, Email y la columna de Acciones (con ancho fijo de 150 píxeles).

#### Filas de Clientes Recorridas con `foreach`
```php
                            <tbody>
                                <?php foreach ($clientes as $cli): ?>
                                    <tr>
                                        <td><?php echo $cli["id_cliente"]; ?></td>
                                        <td><?php echo htmlspecialchars($cli["nombre"] . " " . $cli["apellido"]); ?></td>
                                        <td><?php echo htmlspecialchars($cli["telefono"]); ?></td>
                                        <td><?php echo htmlspecialchars($cli["email"]); ?></td>
                                        <td>
                                            <a href="clientes.php?editar=<?php echo $cli["id_cliente"]; ?>" class="btn btn-warning btn-sm">Editar</a>
                                            <a href="clientes.php?eliminar=<?php echo $cli["id_cliente"]; ?>" class="btn btn-danger btn-sm"
                                               onclick="return confirm('¿Seguro que querés eliminar este cliente?');">Eliminar</a>
                                        </td>
                                    </tr>
                                <?php endforeach; ?>
                            </tbody>
```
* **`foreach ($clientes as $cli)`**: Ciclo que recorre cada cliente obtenido de la base de datos y crea un renglón `<tr>` en la tabla.
* **`$cli["id_cliente"]`**: Muestra el ID único del cliente.
* **`htmlspecialchars($cli["nombre"] . " " . $cli["apellido"])`**: Concatena el nombre y apellido en una sola columna protegida contra código malicioso.
* **`htmlspecialchars($cli["telefono"])`** y **`htmlspecialchars($cli["email"])`**: Muestran los datos de contacto sanitizados.
* **Botón Editar (`btn-warning btn-sm`)**: Botón amarillo que recarga la página enviando `?editar=ID`, cargando los datos de este cliente en el formulario de la izquierda.
* **Botón Eliminar (`btn-danger btn-sm`)**: Botón rojo que llama a la página con `?eliminar=ID`.
  * **`onclick="return confirm('...');"`**: Abre una ventana de confirmación del navegador en JavaScript. Si el usuario presiona "Cancelar", la acción se aborta inmediatamente y el cliente no se borra.
