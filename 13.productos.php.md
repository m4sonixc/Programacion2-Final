# Explicación Exhaustiva y Completa de `productos.php`

Este archivo es el **módulo de gestión de inventario y catálogo de productos** del sistema del *Taller de Pachi*.

Implementa un **CRUD completo** (Crear, Leer, Actualizar y Eliminar) dentro de una **pantalla dividida en dos columnas**:
1. **Listar:** Muestra todos los repuestos y artículos del taller en una tabla, uniendo los datos con la tabla de categorías para mostrar el nombre del rubro al que pertenece cada artículo.
2. **Crear:** Permite registrar nuevos productos indicando su nombre, categoría, precio, stock disponible y descripción.
3. **Editar:** Carga todos los datos del producto seleccionado en el formulario (incluyendo la preselección de su categoría en el menú desplegable) para modificarlo en el lugar.
4. **Eliminar de forma protegida:** Borra productos, pero **impide la eliminación si el producto ya forma parte de alguna venta registrada** para no alterar los registros contables históricos del taller.

## BLOQUE 1: Código PHP (Lógica del Servidor, Validaciones y Base de Datos)

Todo el código que se encuentra entre `<?php` y `?>` se procesa en el servidor antes de renderizar la vista HTML.

### 1. Inclusión de Archivos Obligatorios y Seguridad
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Filtro de autenticación. Verifica que el usuario tenga una sesión activa. Si no está logueado, interrumpe el script y lo expulsa al `login.php`. `require_once` garantiza que el archivo se cargue una sola vez y detiene el sistema si el archivo no existe.
* **`require_once "config/conexion.php";`**: Abre el canal de comunicación con la base de datos MySQL mediante el objeto `$conexion` (usando PDO).

### 2. Inicialización de Variables de Estado
```php
$mensaje = "";

$nombre_editar = "";
$descripcion_editar = "";
$precio_editar = "";
```

* **`$mensaje = "";`**: Variable vacía que contendrá el texto de respuesta o advertencia para el usuario.

* **`$id_editar = "";`**: Almacena el ID del producto cuando se entra en modo edición. Si está vacío, el sistema sabe que el formulario se usará para registrar un producto nuevo; si contiene un número, se usará para actualizarlo.
* **`$nombre_editar`, `$descripcion_editar`, `$precio_editar`, `$stock_editar`, `$id_categoria_editar`**: Variables inicializadas en vacío que se usarán para precargar automáticamente los campos del formulario cuando se elija editar un producto.

### 3. Operación de Eliminación con Control de Clave Foránea (`GET["eliminar"]`)
Se ejecuta cuando en la URL viene el parámetro `eliminar` (por ejemplo: `productos.php?eliminar=12`).

```php
if (isset($_GET["eliminar"])) {
    $id = intval($_GET["eliminar"]);
    try {
        $stmt = $conexion->prepare("DELETE FROM productos WHERE id_producto = ?");
        $stmt->execute([$id]);
        $mensaje = "Producto eliminado correctamente.";
        $tipo_alerta = "success";
    } catch (PDOException $e) {
        $mensaje = "No se puede eliminar el producto porque ya está incluido en una venta.";
        $tipo_alerta = "danger";
    }
}
```
* **`if (isset($_GET["eliminar"]))`**: Evalúa si se presionó el botón de eliminar.
* **`intval(...)`**: Convierte el valor a un número entero estricto para evitar inyecciones maliciosas desde la URL.
* **`try { ... } catch (PDOException $e) { ... }`**:
  * La tabla `detalle_ventas` contiene una clave foránea (*Foreign Key*) vinculada al campo `id_producto`.
  * Si intentamos borrar un repuesto o aceite que ya fue vendido en alguna ocasión, MySQL bloqueará la orden para no destruir los comprobantes de venta del taller.
  * El bloque `catch` atrapa esa excepción de clave foránea y muestra un mensaje comprensible en color rojo (`danger`): *"No se puede eliminar el producto porque ya está incluido en una venta."*
  * Si el artículo nunca formó parte de una venta, se elimina sin problemas y se emite el mensaje verde (`success`): *"Producto eliminado correctamente."*

### 4. Carga de Datos para Edición (`GET["editar"]`)
Se ejecuta cuando el usuario hace clic en el botón amarillo "Editar" de alguna fila de la tabla (por ejemplo: `productos.php?editar=4`).

```php
if (isset($_GET["editar"])) {
    $id_editar = intval($_GET["editar"]);
    $stmt = $conexion->prepare("SELECT * FROM productos WHERE id_producto = ?");
    $stmt->execute([$id_editar]);
    if ($fila = $stmt->fetch()) {
        $nombre_editar = $fila["nombre"];
        $descripcion_editar = $fila["descripcion"];
        $precio_editar = $fila["precio"];
        $stock_editar = $fila["stock"];
        $id_categoria_editar = $fila["id_categoria"];
    }
}
```
* **`intval($_GET["editar"])`**: Sanitiza el identificador recibido como número entero.
* **`SELECT * FROM productos WHERE id_producto = ?`**: Consulta en la base de datos la fila del producto correspondiente a ese ID.
* **`if ($fila = $stmt->fetch())`**: Si el producto existe, extrae cada una de sus columnas y las almacena en las variables correspondientes para prellenar el formulario de la izquierda.

### 5. Procesamiento del Formulario: Crear o Actualizar (`POST`)
Se ejecuta cuando el usuario envía el formulario presionando el botón principal.

```php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $id_producto = $_POST["id_producto"] ?? "";
    $nombre = trim($_POST["nombre"] ?? "");
    $descripcion = trim($_POST["descripcion"] ?? "");
    $precio = floatval($_POST["precio"] ?? -1);
    $stock = intval($_POST["stock"] ?? -1);
    $id_categoria = intval($_POST["id_categoria"] ?? 0);
```
* **`$_SERVER["REQUEST_METHOD"] == "POST"`**: Comprueba que la llamada provenga del envío del formulario.
* **`$id_producto`**: Rescata el valor del campo oculto (vacío si es nuevo, con número si es edición).
* **`trim(...)`**: Remueve espacios en blanco innecesarios en el nombre y la descripción.
* **`floatval($_POST["precio"] ?? -1)`**: Convierte el precio a número con decimales. Si no fue enviado, le asigna `-1` para que falle la validación posterior.
* **`intval($_POST["stock"] ?? -1)`**: Convierte el stock a un número entero. Si no fue enviado, le asigna `-1`.
* **`intval($_POST["id_categoria"] ?? 0)`**: Convierte el ID de la categoría a entero.

#### Validación Estricta de Campos y Reglas Numéricas
```php
    if ($nombre == "" || $id_categoria <= 0 || $precio < 0 || $stock < 0) {
        $mensaje = "Completá todos los campos obligatorios con valores válidos.";
        $tipo_alerta = "danger";
    } else {
```
* Comprueba cuatro condiciones esenciales:
  1. Que el nombre no esté en blanco (`$nombre == ""`).
  2. Que se haya seleccionado una categoría real (`$id_categoria <= 0`).
  3. Que el precio no sea un número negativo (`$precio < 0`).
  4. Que el stock no sea un número negativo (`$stock < 0`).
* Si alguna de estas condiciones falla, cancela el guardado y emite un mensaje en rojo (`danger`).

#### Inserción o Actualización en la Base de Datos
```php
        if ($id_producto == "") {
            $stmt = $conexion->prepare("INSERT INTO productos (nombre, descripcion, precio, stock, id_categoria) VALUES (?, ?, ?, ?, ?)");
            $stmt->execute([$nombre, $descripcion, $precio, $stock, $id_categoria]);
            $mensaje = "Producto agregado correctamente.";
        } else {
            $stmt = $conexion->prepare("UPDATE productos SET nombre = ?, descripcion = ?, precio = ?, stock = ?, id_categoria = ? WHERE id_producto = ?");
            $stmt->execute([$nombre, $descripcion, $precio, $stock, $id_categoria, $id_producto]);
            $mensaje = "Producto actualizado correctamente.";
        }
        $tipo_alerta = "success";
    }
}
```
* **Caso 1: Creación (`$id_producto == ""`):** Como el campo oculto está vacío, ejecuta un `INSERT INTO` para registrar el nuevo producto con sus 5 columnas y define el mensaje de éxito.
* **Caso 2: Edición (`else`):** Como el campo oculto tiene un ID, ejecuta un `UPDATE productos SET ... WHERE id_producto = ?` actualizando los datos de ese registro exacto.
* En ambos casos, define `$tipo_alerta = "success"`.

### 6. Consultas para Llenar el Menú Desplegable y la Tabla de Listado
```php
$categorias = $conexion->query("SELECT id_categoria, nombre FROM categorias ORDER BY nombre")->fetchAll();
```
* Consulta todas las categorías ordenadas alfabéticamente para construir las opciones del menú desplegable (`<select>`).

```php
$sql_lista = "SELECT p.*, c.nombre AS nombre_categoria 
              FROM productos p 
              INNER JOIN categorias c ON p.id_categoria = c.id_categoria 
              ORDER BY p.id_producto DESC";
$productos = $conexion->query($sql_lista)->fetchAll();
```
* **`p.*`**: Selecciona todos los campos de la tabla `productos` (`id_producto`, `nombre`, `precio`, `stock`, etc.).
* **`c.nombre AS nombre_categoria`**: Obtiene el nombre legible de la categoría desde la tabla `categorias`.
* **`INNER JOIN categorias c ON p.id_categoria = c.id_categoria`**: Cruza ambas tablas por su ID común para que en la tabla no se vea un número de categoría frío, sino su nombre real (ej: "Lubricantes", "Frenos", etc.).
* **`ORDER BY p.id_producto DESC`**: Ordena de forma descendente para que el último producto creado aparezca primero en la lista.
* **`fetchAll()`**: Guarda todos los productos devueltos en la variable `$productos`.

### 6. Columna Derecha: Tabla de Inventario (`col-md-8`)

#### Filas de Productos con `foreach`
```php
                            <tbody>
                                <?php foreach ($productos as $prod): ?>
                                    <tr>
                                        <td><?php echo $prod["id_producto"]; ?></td>
                                        <td><?php echo htmlspecialchars($prod["nombre"]); ?></td>
                                        <td><?php echo htmlspecialchars($prod["nombre_categoria"]); ?></td>
                                        <td>$<?php echo number_format($prod["precio"], 2, ",", "."); ?></td>

                                        <td>
                                            <a href="productos.php?editar=<?php echo $prod["id_producto"]; ?>" class="btn btn-warning btn-sm">Editar</a>
                                            <a href="productos.php?eliminar=<?php echo $prod["id_producto"]; ?>" class="btn btn-danger btn-sm"
                                               onclick="return confirm('¿Seguro que querés eliminar este producto?');">Eliminar</a>
                                        </td>
                                    </tr>
                                <?php endforeach; ?>
                            </tbody>
```
* **`foreach ($productos as $prod)`**: Itera por cada producto devuelto de la base de datos y genera una fila `<tr>`.
* **`$prod["id_producto"]`**: Muestra el ID único del producto.
* **`htmlspecialchars($prod["nombre"])`**: Muestra el nombre del artículo protegido contra ataques XSS.
* **`htmlspecialchars($prod["nombre_categoria"])`**: Muestra el nombre real de la categoría traído mediante el `INNER JOIN`.
* **`number_format($prod["precio"], 2, ",", ".")`**: Formatea el precio numérico a estilo monetario: 2 decimales, coma para los centavos y punto para los miles (ej: `$4.850,50`).
* **`$prod["stock"]`**: Muestra la cantidad actual de unidades físicas disponibles en el taller.
* **Botón Editar (`btn-warning btn-sm`):** Enlace amarillo que recarga la página con `?editar=ID` para cargar los datos de ese producto en el formulario de la izquierda.
* **Botón Eliminar (`btn-danger btn-sm`):** Enlace rojo que llama a la página con `?eliminar=ID`.
  * **`onclick="return confirm('...');"`**: Ventana emergente nativa de JavaScript. Si el usuario presiona "Cancelar", aborta la operación y el producto no se elimina.
