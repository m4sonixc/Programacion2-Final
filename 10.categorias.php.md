# Explicación Exhaustiva y Completa de `categorias.php`

Este archivo es el **módulo integral de gestión de categorías** del sistema del *Taller de Pachi*. 

Implementa lo que en programación se conoce como un **CRUD completo** (Crear, Leer, Actualizar y Eliminar) dentro de una **única pantalla**:
1. **Listar:** Muestra todas las categorías existentes en una tabla.
2. **Crear:** Permite registrar una nueva categoría.
3. **Editar:** Carga los datos de una categoría seleccionada en el formulario para modificarlos.
4. **Eliminar:** Borra una categoría, controlando de forma segura que no tenga productos asociados para no romper la base de datos.

---

## BLOQUE 1: Código PHP (Lógica del Servidor y Base de Datos)

Todo el código contenido entre `<?php` y `?>` se ejecuta en el servidor antes de generar la respuesta visual que ve el usuario.

### 1. Inclusión de Archivos y Seguridad
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Invoca el script de control de sesión. Si el visitante no inició sesión con usuario y contraseña, este archivo frena el proceso y lo expulsa automáticamente a `login.php`. `require_once` garantiza que el archivo se cargue una sola vez y detiene todo si el archivo no existe.
* **`require_once "config/conexion.php";`**: Conecta a la base de datos MySQL mediante el objeto `$conexion` (usando PDO).

---

### 2. Inicialización de Variables de Estado
```php
$mensaje = "";
$tipo_alerta = "";
$id_editar = "";
$nombre_editar = "";
$descripcion_editar = "";
```
* **`$mensaje = "";`**: Cadena de texto vacía que almacenará el aviso informativo para el usuario (por ejemplo: *"Categoría eliminada correctamente"*).
* **`$tipo_alerta = "";`**: Guardará el estilo de color de Bootstrap para el mensaje (`"success"` para color verde o `"danger"` para color rojo).
* **`$id_editar = "";`**: Almacena el ID de la categoría que se desea modificar. Si está vacío, el sistema sabe que el formulario se utilizará para crear una categoría nueva; si tiene un número, se usará para editarla.
* **`$nombre_editar = "";`**: Almacena el nombre de la categoría para rellenar la casilla de texto en caso de edición.
* **`$descripcion_editar = "";`**: Almacena la descripción de la categoría para rellenar el área de texto en caso de edición.

### 3. Operación de Eliminación (`GET["eliminar"]`)
Se ejecuta cuando en la URL viene el parámetro `eliminar` (por ejemplo: `categorias.php?eliminar=3`).

```php
if (isset($_GET["eliminar"])) {
    $id = intval($_GET["eliminar"]);
    try {
        $stmt = $conexion->prepare("DELETE FROM categorias WHERE id_categoria = ?");
        $stmt->execute([$id]);
        $mensaje = "Categoría eliminada correctamente.";
        $tipo_alerta = "success";
    } catch (PDOException $e) {
        $mensaje = "No se puede eliminar la categoría porque tiene productos asociados.";
        $tipo_alerta = "danger";
    }
}
```
Este bloque gestiona la eliminación segura de registros desde la URL, protegiendo la consulta contra inyecciones SQL y controlando errores de integridad referencial en la base de datos:

1. **Detección del parámetro (`isset($_GET["eliminar"])`):** Verifica si se recibió el parámetro `eliminar` a través de la URL (por ejemplo, `categorias.php?eliminar=5`).
2. **Sanitización del dato (`intval(...)`):** Convierte el valor recibido a un número entero (`$id`) como primera capa de limpieza antes de procesarlo.
3. **Consulta preparada (`try`):** Prepara y ejecuta la sentencia `DELETE` utilizando marcadores de posición (`?`) en PDO para evitar inyecciones SQL. Si la operación tiene éxito, define un mensaje de confirmación y el tipo de alerta visual (`"success"`).
4. **Control de excepciones (`catch (PDOException $e)`):** Captura cualquier error lanzado por la base de datos—principalmente restricciones de clave foránea (*Foreign Key*) cuando la categoría aún tiene productos vinculados—evitando que el sistema se detenga y mostrando una alerta amigable (`"danger"`).

* **`if (isset($_GET["eliminar"]))`**: Pregunta si se hizo clic en el enlace para eliminar una categoría.
* **`intval($_GET["eliminar"])`**: Transforma el dato recibido forzosamente a un número entero. Es una protección indispensable para evitar inyecciones de código malicioso a través de la URL.
* **`try { ... } catch (PDOException $e) { ... }`**: Control de integridad referencial.
  * En la base de datos, la tabla `productos` está conectada con la tabla `categorias` mediante una clave foránea (*Foreign Key*).
  * Si intentamos borrar una categoría que contiene productos vinculados, MySQL arrojará un error de restricción de clave.
  * El bloque `catch` atrapa ese error técnico y, en lugar de romper el sistema, le muestra un mensaje claro y amigable al usuario: *"No se puede eliminar la categoría porque tiene productos asociados"*, con estilo rojo (`danger`).
  * Si la categoría no tenía ningún producto, se borra exitosamente y muestra el mensaje verde (`success`).

### 4. Carga de Datos para Edición (`GET["editar"]`)
Se ejecuta cuando el usuario hace clic en el botón amarillo "Editar" de alguna fila (por ejemplo: `categorias.php?editar=2`).

```php
if (isset($_GET["editar"])) {
    $id_editar = intval($_GET["editar"]);
    $stmt = $conexion->prepare("SELECT * FROM categorias WHERE id_categoria = ?");
    $stmt->execute([$id_editar]);
    if ($fila = $stmt->fetch()) {
        $nombre_editar = $fila["nombre"];
        $descripcion_editar = $fila["descripcion"];
    }
}
```
Este bloque recupera los datos de una categoría específica desde la base de datos para precargarlos en un formulario de edición, siguiendo cinco pasos:

1. **Detección del parámetro en la URL (`isset($_GET["editar"])`):** Verifica si se recibió el parámetro `editar` mediante una petición GET (por ejemplo, `categorias.php?editar=3`).
2. **Sanitización del identificador (`intval(...)`):** Convierte el valor recibido en la URL estrictamente a un número entero (`$id_editar`) como primera capa de seguridad para evitar valores maliciosos.
3. **Consulta preparada (`$conexion->prepare(...)`):** Prepara la sentencia `SELECT` utilizando un marcador de posición (`?`) para filtrar por `id_categoria`, protegiendo la consulta contra inyecciones SQL.
4. **Ejecución con parámetro (`$stmt->execute([...])`):** Ejecuta la consulta enviando el ID sanitizado dentro de un arreglo para reemplazar el marcador de posición de forma segura.
5. **Extracción y asignación (`$stmt->fetch()`):** Obtiene el registro coincidente de la base de datos. Si la categoría existe, guarda los valores de las columnas `nombre` y `descripcion` en las variables `$nombre_editar` y `$descripcion_editar` para mostrarlas en los campos del formulario.

### 5. Procesamiento del Formulario: Crear o Actualizar (`POST`)
Se ejecuta cuando el usuario presiona el botón principal del formulario para enviar datos.

```php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $id_categoria = $_POST["id_categoria"] ?? "";
    $nombre = trim($_POST["nombre"] ?? "");
    $descripcion = trim($_POST["descripcion"] ?? "");
```
Este bloque captura y prepara los datos enviados desde un formulario HTML antes de procesarlos o guardarlos en la base de datos:

* **`$_SERVER["REQUEST_METHOD"] == "POST"`:** Verifica que la petición HTTP se haya realizado mediante el método **POST** (es decir, que el usuario haya enviado el formulario) antes de ejecutar la lógica de guardado o actualización.
* **`$_POST[...]`:** Arreglo superglobal de PHP que recoge los valores enviados desde los campos del formulario según su atributo `name` (`id_categoria`, `nombre` y `descripcion`).
* **`?? ""` (Operador de fusión de null):** Evalúa si el dato existe y no es `null`. Si el campo no fue enviado en la petición, le asigna una cadena vacía (`""`) por defecto para evitar errores de índice indefinido (`Undefined array key`).
* **`trim(...)`:** Función que elimina los espacios en blanco innecesarios al inicio y al final del texto ingresado por el usuario, garantizando datos limpios antes de validarlos o insertarlos en la base de datos.

* **`$_SERVER["REQUEST_METHOD"] == "POST"`**: Comprueba que la solicitud fue enviada mediante el método POST del formulario.
* **`$id_categoria`**: Rescata el valor del campo oculto. Si está vacío, el usuario está agregando; si contiene un ID, está editando.
* **`trim(...)`**: Elimina espacios en blanco accidentales al principio y al final del texto.
* **`?? ""`**: Si algún campo no fue enviado, le asigna un texto vacío por defecto.

#### Validación y Decisión (Insertar o Modificar)
```php
    if ($nombre == "") {
        $mensaje = "El nombre de la categoría es obligatorio.";
        $tipo_alerta = "danger";
    } else {
        if ($id_categoria == "") {
            $stmt = $conexion->prepare("INSERT INTO categorias (nombre, descripcion) VALUES (?, ?)");
            $stmt->execute([$nombre, $descripcion]);
            $mensaje = "Categoría agregada correctamente.";
        } else {
            $stmt = $conexion->prepare("UPDATE categorias SET nombre = ?, descripcion = ? WHERE id_categoria = ?");
            $stmt->execute([$nombre, $descripcion, $id_categoria]);
            $mensaje = "Categoría actualizada correctamente.";
        }
        $tipo_alerta = "success";
    }
}
```
Este bloque procesa el envío del formulario de categorías, validando los datos y decidiendo si debe crear un registro nuevo o modificar uno existente:

1. **Validación de campo obligatorio (`if ($nombre == "")`):** Comprueba si el nombre de la categoría está vacío. Si falta, asigna el mensaje `"El nombre de la categoría es obligatorio."` y define el tipo de alerta como `"danger"` (error) para interrumpir el guardado.
2. **Creación de nueva categoría (`if ($id_categoria == "")`):** Si el nombre es válido y no se recibió un ID de categoría, interpreta que es un registro nuevo. Prepara y ejecuta una consulta preparada `INSERT INTO` pasando el nombre y la descripción de forma segura mediante parámetros (`?`), y define el mensaje de confirmación.
3. **Actualización de categoría existente (`else`):** Si el campo `$id_categoria` contiene un valor, interpreta que se está editando un registro previo. Prepara y ejecuta una consulta `UPDATE` filtrando por `id_categoria` para sobrescribir su nombre y descripción.
4. **Notificación de éxito (`$tipo_alerta = "success"`):** Tanto si se insertó como si se actualizó el registro correctamente, establece el estado de la alerta en `"success"` para mostrar la confirmación visual al usuario.

### 6. Consulta General para Listar las Categorías
```php
$categorias = $conexion->query("SELECT * FROM categorias ORDER BY id_categoria DESC")->fetchAll();
```
* Realiza una consulta directa a la base de datos para obtener todos los registros de la tabla `categorias`.
* **`ORDER BY id_categoria DESC`**: Ordena los registros de forma descendente, haciendo que la categoría más reciente siempre aparezca en el primer lugar de la tabla.
* **`fetchAll()`**: Devuelve todas las filas encontradas como un arreglo asociativo y las guarda en la variable `$categorias`.

### 5. Columna Izquierda: Formulario Dinámico (`col-md-4`)
Ocupa 4 de las 12 columnas en pantallas medianas o grandes (un tercio del ancho de la pantalla).

```html
            <div class="col-md-4 mb-4">
                <div class="card shadow-sm">
                    <div class="card-header bg-primary text-white">
                        <?php echo ($id_editar != "") ? "Editar Categoría" : "Nueva Categoría"; ?>
                    </div>
```
* **`card shadow-sm`**: Tarjeta con bordes redondeados y sombra sutil.
* **Encabezado Inteligente:**
  * Utiliza un operador ternario: `($id_editar != "") ? "Editar Categoría" : "Nueva Categoría"`.
  * Si estamos editando, el título dice "Editar Categoría"; si no, dice "Nueva Categoría".

#### Controles del Formulario
```html
                    <div class="card-body">
                        <form method="POST" action="categorias.php">
                            <input type="hidden" name="id_categoria" value="<?php echo $id_editar; ?>">
```
* **`action="categorias.php"`**: Envía los datos a este mismo archivo mediante el método POST.
* **`<input type="hidden" name="id_categoria"...>`**: Campo oculto indispensable. Lleva el valor de `$id_editar`. Si está vacío, PHP creará una categoría nueva; si tiene un ID, actualizará esa categoría existente.

```php
                            <div class="mb-3">
                                <label class="form-label">Nombre</label>
                                <input type="text" name="nombre" class="form-control" required
                                       value="<?php echo htmlspecialchars($nombre_editar); ?>">
                            </div>
                            <div class="mb-3">
                                <label class="form-label">Descripción</label>
                                <textarea name="descripcion" class="form-control" rows="3"><?php echo htmlspecialchars($descripcion_editar); ?></textarea>
                            </div>
```
* **Campo Nombre (`input type="text"`):** Es obligatorio (`required`). Si estamos en modo edición, su atributo `value` se precarga con el nombre actual de la categoría gracias a `$nombre_editar`.
* **Campo Descripción (`textarea`):** Caja de texto multilínea de 3 filas de alto (`rows="3"`). Si estamos editando, se rellena con `$descripcion_editar`.
* **`htmlspecialchars(...)`**: Protege los textos precargados contra ataques de Cross-Site Scripting (XSS).

#### Botones del Formulario
```php
                            <button type="submit" class="btn btn-primary w-100">
                                <?php echo ($id_editar != "") ? "Guardar Cambios" : "Agregar Categoría"; ?>
                            </button>
                            <?php if ($id_editar != ""): ?>
                                <a href="categorias.php" class="btn btn-secondary w-100 mt-2">Cancelar</a>
                            <?php endif; ?>
                        </form>
                    </div>
                </div>
            </div>
```
* **Botón Principal (`btn-primary w-100`):** Ocupa todo el ancho. El texto del botón cambia de forma automática: si estamos editando muestra *"Guardar Cambios"*, y si estamos creando muestra *"Agregar Categoría"*.
* **Botón Cancelar (`btn-secondary w-100 mt-2`):** Solo aparece cuando estamos editando (`$id_editar != ""`). Al presionarlo, redirige a `categorias.php` limpio, limpiando el formulario y saliendo del modo edición.

#### Filas de Datos Recorridas con `foreach`
```php
                            <tbody>
                                <?php foreach ($categorias as $cat): ?>
                                    <tr>
                                        <td><?php echo $cat["id_categoria"]; ?></td>
                                        <td><?php echo htmlspecialchars($cat["nombre"]); ?></td>
                                        <td><?php echo htmlspecialchars($cat["descripcion"]); ?></td>
                                        <td>
                                            <a href="categorias.php?editar=<?php echo $cat["id_categoria"]; ?>" class="btn btn-warning btn-sm">Editar</a>
                                            <a href="categorias.php?eliminar=<?php echo $cat["id_categoria"]; ?>" class="btn btn-danger btn-sm"
                                               onclick="return confirm('¿Seguro que querés eliminar esta categoría?');">Eliminar</a>
                                        </td>
                                    </tr>
                                <?php endforeach; ?>
                            </tbody>
```
* **`foreach ($categorias as $cat)`**: Recorre una a una todas las categorías registradas en la base de datos y genera una fila `<tr>` por cada una.
* **`$cat["id_categoria"]`**: Imprime el número identificador.
* **`htmlspecialchars($cat["nombre"])`** y **`htmlspecialchars($cat["descripcion"])`**: Muestran el nombre y la descripción sanitizados para que no puedan ejecutarse códigos scripts maliciosos.
* **Botón Editar (`btn-warning btn-sm`)**: Enlace de color amarillo que recarga la página pasando el parámetro `?editar=ID`, lo que hace que los datos de esa fila suban al formulario de la izquierda.
* **Botón Eliminar (`btn-danger btn-sm`)**: Enlace de color rojo que llama a la página con el parámetro `?eliminar=ID`.
  * **`onclick="return confirm('...');"`**: Ventana emergente nativa de JavaScript que le pide confirmación al usuario antes de ejecutar el borrado. Si el usuario hace clic en "Cancelar", la orden se interrumpe y no se borra nada.
