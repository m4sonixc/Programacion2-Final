# Explicación Exhaustiva y Completa de `editar_venta.php`

Este archivo es el **módulo de edición y modificación de ventas** del sistema del *Taller de Pachi*. 

Su función es permitir corregir una venta ya realizada: cambiar el cliente, agregar o quitar productos, o modificar cantidades y precios. Lo más importante y complejo de este archivo es que **recalcula el stock de forma inteligente**: devuelve a la base de datos los productos que estaban antes y descuenta los nuevos productos que se hayan configurado.

---

## BLOQUE 1: Código PHP Inicial (Lógica del Servidor)

Este bloque se ejecuta en el servidor antes de mostrar la página web.

### 1. Inclusión de Archivos Obligatorios
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Invoca el filtro de autenticación. Si el usuario no inició sesión, este archivo detiene todo y lo expulsa al `login.php`. La palabra `require_once` asegura que se cargue una única vez y que, si el archivo falta o no se encuentra, la ejecución se interrumpa inmediatamente por seguridad.
* **`require_once "config/conexion.php";`**: Carga la conexión a la base de datos MySQL mediante la variable `$conexion` utilizando la interfaz PDO.

---

### 2. Captura del Parámetro Inicial e Inicialización de Variables
```php
$id_venta = intval($_GET["id"] ?? 0);
$error = "";
```
* **`$_GET["id"]`**: Lee de la barra de direcciones del navegador el identificador de la venta que se desea editar (por ejemplo, en `editar_venta.php?id=4`, el valor es `4`).
* **`?? 0`**: Operador de fusión por nulo. Si nadie envía el parámetro `id` en la URL, toma por defecto el número `0` para que el sistema no arroje errores de variable indefinida.
* **`intval(...)`**: Convierte el dato forzosamente a un número entero. Es una defensa contra ataques de inyección SQL, asegurando que solo viajen números.
* **`$error = "";`**: Variable que arranca como una cadena de texto vacía. Si algo falla durante el guardado, aquí se guardará el mensaje de error para mostraselo al usuario.

---

### 3. Procesamiento y Guardado de la Modificación (`POST`)
Este bloque únicamente se activa cuando el usuario presiona el botón "Guardar Cambios" del formulario.

```php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $id_venta = intval($_POST["id_venta"]);
    $id_cliente = intval($_POST["id_cliente"] ?? 0);
    $productos_ids = $_POST["id_producto"] ?? [];
    $cantidades = $_POST["cantidad"] ?? [];
    $precios = $_POST["precio"] ?? [];
```
* **`if ($_SERVER["REQUEST_METHOD"] == "POST")`**: Verifica si la página fue llamada para guardar datos mediante el método HTTP POST.
* **`$id_venta = intval($_POST["id_venta"]);`**: Rescata el ID de la venta desde un campo oculto del formulario y lo convierte en entero.
* **`$id_cliente = intval($_POST["id_cliente"] ?? 0);`**: Obtiene el ID del cliente seleccionado.
* **`$productos_ids = $_POST["id_producto"] ?? [];`**: Arreglo que contiene todos los IDs de los productos que quedaron en la tabla de detalle.
* **`$cantidades = $_POST["cantidad"] ?? [];`**: Arreglo con las cantidades de cada producto.
* **`$precios = $_POST["precio"] ?? [];`**: Arreglo con los precios unitarios de cada producto.
* **`?? []`**: Si se borraron todos los productos de la tabla, asigna un arreglo vacío para no generar advertencias en PHP.

---

### 4. Validaciones de Reglas de Negocio en el Servidor
```php
    if ($id_cliente <= 0 || count($productos_ids) == 0) {
        $error = "Debés seleccionar un cliente y dejar al menos un producto.";
    } else {
```
* **`$id_cliente <= 0`**: Verifica que el usuario haya seleccionado un cliente real y no la opción en blanco.
* **`count($productos_ids) == 0`**: Cuenta cuántos productos hay en la lista. Si es cero, significa que el usuario quitó todos los productos de la tabla.
* Si alguna de estas condiciones falla, asigna el texto de aviso a `$error` y cancela el guardado.

---

### 5. Cálculo del Total de la Venta en el Servidor
```php
        $total_venta = 0;
        for ($i = 0; $i < count($productos_ids); $i++) {
            $total_venta += intval($cantidades[$i]) * floatval($precios[$i]);
        }
```
* **`$total_venta = 0;`**: Variable acumuladora.
* **`for ($i = 0; $i < count($productos_ids); $i++)`**: Ciclo que recorre posición por posición cada producto cargado.
* **`intval($cantidades[$i])`**: Fuerza la cantidad a ser un entero.
* **`floatval($precios[$i])`**: Fuerza el precio a ser un número con decimales.
* **`+=`**: Multiplica la cantidad por el precio y lo suma al acumulador general. Esto garantiza que el total sea calculado de forma segura por el servidor y no dependa de lo que mande el navegador.

---

### 6. Transacción en la Base de Datos: Restauración, Limpieza y Actualización
```php
        $conexion->beginTransaction();
        try {
```
* **`$conexion->beginTransaction();`**: Abre una transacción en MySQL. Significa que todas las consultas siguientes se consideran un único paquete. Si todo sale perfecto se aplican los cambios, pero si ocurre un solo fallo, se deshace todo para no dejar la base de datos inconsistente.
* **`try {`**: Abre el bloque de captura de errores.

#### Paso A: Devolver el Stock Antiguo al Inventario
```php
            $stmt_old = $conexion->prepare("SELECT id_producto, cantidad FROM detalle_ventas WHERE id_venta = ?");
            $stmt_old->execute([$id_venta]);
            $items_old = $stmt_old->fetchAll();
            $stmt_st = $conexion->prepare("UPDATE productos SET stock = stock + ? WHERE id_producto = ?");
            foreach ($items_old as $item) {
                $stmt_st->execute([$item["cantidad"], $item["id_producto"]]);
            }
```
Este bloque se ejecuta antes de guardar los cambios cuando se edita una venta existente. Su función es consultar los productos que formaban parte de la versión original de la operación y devolver sus cantidades al inventario, dejando el stock limpio para luego descontar los nuevos valores modificados.

#### Desglose completo del funcionamiento:

1. **Consulta de los artículos anteriores (`$stmt_old` y `execute()`):**
   * Prepara y ejecuta una sentencia `SELECT` sobre la tabla `detalle_ventas` filtrando por el identificador de la venta (`$id_venta`).
   * Recupera únicamente el identificador de cada producto (`id_producto`) y la cantidad (`cantidad`) que se habían registrado originalmente antes de la edición, utilizando marcadores de posición (`?`) para prevenir inyecciones SQL.

2. **Almacenamiento de los datos previos (`$items_old = $stmt_old->fetchAll()`):**
   * Extrae todas las filas obtenidas por la consulta en una sola operación y las guarda como un arreglo en `$items_old` (nombrado así para diferenciar los registros antiguos de los nuevos que vienen del formulario).

3. **Preparación de la restauración de inventario (`$stmt_st`):**
   * Define fuera del ciclo una consulta `UPDATE` sobre la tabla `productos` para sumar unidades a la columna `stock`. Prepararla una sola vez como molde mejora el rendimiento del servidor al evitar recompilar la misma instrucción SQL en cada vuelta.

4. **Devolución del stock mediante recorrido (`foreach`):**
   * Itera sobre cada elemento almacenado en `$items_old` y ejecuta `$stmt_st` en cada paso, sumando nuevamente la cantidad original (`$item["cantidad"]`) al stock disponible del producto correspondiente (`$item["id_producto"]`).

#### Paso B: Borrar el Detalle Viejo
```php
            $stmt_del = $conexion->prepare("DELETE FROM detalle_ventas WHERE id_venta = ?");
            $stmt_del->execute([$id_venta]);
```
* Elimina todos los renglones que existían en la tabla `detalle_ventas` correspondientes a este número de venta, dejando la venta lista para recibir la nueva lista de artículos.

#### Paso C: Actualizar la Cabecera de la Venta
```php
            $stmt_upd = $conexion->prepare("UPDATE ventas SET id_cliente = ?, total = ? WHERE id_venta = ?");
            $stmt_upd->execute([$id_cliente, $total_venta, $id_venta]);
```
* Modifica la tabla principal `ventas`, asignando el nuevo cliente seleccionado (`id_cliente`) y el nuevo total calculado (`total_venta`) en la fila correspondiente a esta venta (`WHERE id_venta = ?`).

#### Paso D: Insertar el Nuevo Detalle y Descontar el Nuevo Stock
```php
            $stmt_det = $conexion->prepare("INSERT INTO detalle_ventas (id_venta, id_producto, cantidad, precio_unitario, subtotal) VALUES (?, ?, ?, ?, ?)");
            $stmt_stock = $conexion->prepare("UPDATE productos SET stock = stock - ? WHERE id_producto = ?");
        
            for ($i = 0; $i < count($productos_ids); $i++) {
                $id_prod = intval($productos_ids[$i]);
                $cant = intval($cantidades[$i]);
                $prec = floatval($precios[$i]);
                $sub = $cant * $prec;

                $stmt_det->execute([$id_venta, $id_prod, $cant, $prec, $sub]);
                $stmt_stock->execute([$cant, $id_prod]);
            }
```
Este bloque recorre cada artículo incluido en el carrito de compras para guardarlo individualmente en el detalle de la operación y descontar de inmediato las unidades vendidas del inventario.

#### Desglose completo del funcionamiento:

1. **Recorrido sincronizado de arreglos paralelos (`for` y `count($productos_ids)`):**
   * Inicia un ciclo controlado por el índice `$i` que avanza desde `0` hasta el total de productos seleccionados.
   * Dado que los datos llegan desde el formulario en listas separadas pero ordenadas por posición, el mismo índice `$i` permite extraer al mismo tiempo el identificador, la cantidad y el precio correspondientes a una misma línea de venta.

2. **Sanitización y conversión de tipos de datos (`intval()` y `floatval()`):**
   * Como toda información enviada desde formularios web llega originalmente como cadena de texto (*string*), cada valor se convierte a su tipo numérico estricto antes de operar con él:
     * **`$id_prod` y `$cant` (`intval`):** Aseguran que tanto el identificador del producto como la cantidad vendida sean números enteros puros.
     * **`$prec` (`floatval`):** Convierte el precio unitario a un número decimal para conservar la precisión de los centavos.

3. **Cálculo del subtotal por artículo (`$sub = $cant * $prec`):**
   * Multiplica la cantidad vendida por el precio unitario de ese producto específico para obtener el importe parcial de esa fila.

4. **Inserción en el detalle de la venta (`$stmt_det->execute([...])`):**
   * Reutiliza la sentencia preparada previamente para guardar el registro individual en la tabla `detalle_ventas`.
   * Vincula el artículo a la operación principal mediante `$id_venta` (el ID recién generado en la cabecera) junto con el producto, la cantidad, el precio histórico al momento de la venta y el subtotal calculado.

5. **Actualización inmediata del inventario (`$stmt_stock->execute([...])`):**
   * En la misma vuelta del ciclo, ejecuta la sentencia preparada de actualización sobre la tabla de productos para restar del stock disponible la cantidad vendida (`$cant`) del producto exacto (`$id_prod`), manteniendo el inventario sincronizado en tiempo real.

#### Paso E: Confirmación o Cancelación de Cambios
```php
            $conexion->commit();
            header("Location: ver_venta.php?id=" . $id_venta);
            exit();
        } catch (Exception $e) {
            $conexion->rollBack();
            $error = "Ocurrió un error al actualizar la venta.";
        }
    }
}
```
* **`$conexion->commit();`**: Confirma y consolida definitivamente todas las consultas realizadas en la base de datos.
* **`header("Location: ver_venta.php?id=" . $id_venta);` y `exit();`**: Redirige al usuario a la página de ver venta para mostrar el resultado final y corta la ejecución del script.
* **`catch (Exception $e)`**: Si ocurrió algún error o fallo en cualquier consulta del bloque `try`, salta aquí.
* **`$conexion->rollBack();`**: Anula y revierte absolutamente todos los cambios hechos durante la transacción (no devuelve stock, no borra el detalle viejo ni actualiza nada), protegiendo la base de datos.
* Asigna el mensaje de error a la variable `$error`.

### 7. Consultas para Cargar la Información Existente en Pantalla
Si la página se carga de forma normal (para ver el formulario y editar), se ejecutan estas consultas para prellenar los campos:

```php
$stmt_v = $conexion->prepare("SELECT * FROM ventas WHERE id_venta = ?");
$stmt_v->execute([$id_venta]);
$venta = $stmt_v->fetch();
if (!$venta) {
    header("Location: ventas.php");
    exit();
}
```
Este bloque verifica que el identificador recibido corresponda realmente a una venta registrada en la base de datos antes de permitir cargar sus datos para editarla o visualizarla, evitando errores en la interfaz si el registro no existe o fue eliminado.

#### Desglose completo del funcionamiento:

1. **Preparación de la consulta de búsqueda (`$stmt_v = $conexion->prepare(...)`):**
   * Prepara una sentencia SQL `SELECT` sobre la tabla `ventas` filtrando por la columna `id_venta` mediante un marcador de posición (`?`). Esto protege la consulta contra posibles inyecciones SQL.

2. **Ejecución con el identificador sanitizado (`$stmt_v->execute([$id_venta])`):**
   * Ejecuta la sentencia preparada enviando el valor entero de `$id_venta` para buscar la coincidencia exacta en la base de datos.

3. **Extracción de un único registro (`$venta = $stmt_v->fetch()`):**
   * A diferencia de `fetchAll()`, el método **`fetch()`** extrae una sola fila de resultados (ya que el ID de venta es una clave primaria única).
   * Si la venta existe, `$venta` almacena un arreglo con todos sus datos; si no se encuentra ningún registro con ese ID, PDO devuelve el valor booleano **`false`**.

4. **Control de acceso y redirección preventiva (`if (!$venta)`):**
   * Evalúa si la variable `$venta` está vacía o es `false` (negación lógica `!`).
   * Si la venta no existe (por ejemplo, si el usuario ingresó manualmente un ID inexistente en la URL), redirige inmediatamente al listado principal (`ventas.php`) mediante **`header()`** y detiene la ejecución del archivo con **`exit()`** para evitar que el resto de la página intente leer datos inexistentes.

```php
$sql_det = "SELECT d.*, p.nombre AS producto_nombre 
            FROM detalle_ventas d 
            INNER JOIN productos p ON d.id_producto = p.id_producto 
            WHERE d.id_venta = ?";
$stmt_det = $conexion->prepare($sql_det);
$stmt_det->execute([$id_venta]);
$detalles = $stmt_det->fetchAll();
```
Este bloque obtiene la lista completa de los productos específicos que forman parte de una venta determinada, cruzando los registros del detalle con el catálogo de productos para recuperar el nombre comercial de cada artículo.

#### Desglose completo del funcionamiento:

1. **Alias de tablas (`detalle_ventas d` y `productos p`):**
   * Asigna abreviaturas cortas a ambas tablas (`d` para el detalle y `p` para productos). Esto simplifica la escritura de la consulta y evita errores de ambigüedad al referenciar columnas con el mismo nombre (como `id_producto`).

2. **Selección combinada y alias de columna (`d.*` y `AS producto_nombre`):**
   * **`d.*`:** Selecciona todas las columnas propias de la tabla `detalle_ventas` (cantidad, precio histórico de venta, subtotal, etc.).
   * **`p.nombre AS producto_nombre`:** Trae únicamente el nombre del artículo desde la tabla `productos` y lo renombra como `producto_nombre` para identificarlo claramente al mostrarlo en pantalla o en un comprobante.

3. **Relación entre tablas (`INNER JOIN productos p ON ...`):**
   * Conecta cada línea del detalle con su ficha correspondiente en la tabla `productos` comparando el identificador `id_producto` en ambas tablas.

4. **Filtrado por venta específica (`WHERE d.id_venta = ?`):**
   * Limita la búsqueda exclusivamente a los artículos que pertenecen a la venta identificada por `$id_venta`, utilizando un marcador de posición (`?`) para prevenir inyecciones SQL.

5. **Preparación, ejecución y extracción (`prepare()`, `execute()`, `fetchAll()`):**
   * Prepara la consulta de forma segura en `$stmt_det`, la ejecuta enviando el valor de `$id_venta` y extrae todas las filas coincidentes en un solo arreglo dentro de la variable `$detalles`, listo para ser recorrido en la vista de edición o detalle de factura.
   
```php
$clientes = $conexion->query("SELECT id_cliente, nombre, apellido FROM clientes ORDER BY nombre")->fetchAll();
$productos = $conexion->query("SELECT id_producto, nombre, precio, stock FROM productos ORDER BY nombre")->fetchAll();
```
* **`$clientes`**: Obtiene todos los clientes del sistema ordenados alfabéticamente para armar el menú desplegable.
* **`$productos`**: Obtiene todos los productos del inventario con su precio y stock para el menú selector.

### 1. Función `cargarPrecio()`
```javascript
function cargarPrecio() {
    let select = document.getElementById("selectProducto");
    let opcion = select.options[select.selectedIndex];
    document.getElementById("inputPrecio").value = opcion.getAttribute("data-precio");
}
```
Esta función se encarga de detectar qué producto eligió el usuario en la lista desplegable y cargar automáticamente su precio correspondiente en el campo numérico del formulario, agilizando la carga de ventas y evitando errores de tipeo manual.

#### Desglose completo del funcionamiento:

1. **Referencia al selector de productos (`getElementById("selectProducto")`):**
   * Localiza en el documento HTML el menú desplegable (`<select>`) donde se listan todos los artículos disponibles del catálogo y lo guarda en la variable `select`.

2. **Identificación de la opción activa (`select.options[select.selectedIndex]`):**
   * Accede a la lista interna de opciones del selector (`options`) utilizando la posición exacta de la fila que el usuario acaba de elegir (`selectedIndex`). De esta forma obtiene el elemento HTML `<option>` específico del producto seleccionado.

3. **Lectura del atributo personalizado (`opcion.getAttribute("data-precio")`):**
   * Extrae el valor almacenado dentro del atributo HTML5 `data-precio` de esa opción. Al incrustar el precio directamente en cada `<option>` al cargar la página desde PHP, JavaScript puede leerlo al instante en el navegador sin necesidad de hacer una nueva consulta al servidor.

4. **Asignación automática al campo de entrada (`inputPrecio.value`):**
   * Escribe el precio extraído directamente dentro de la caja de texto o campo numérico `inputPrecio`, dejándolo listo para que el usuario confirme la cantidad y agregue el artículo al detalle de la venta.

### 2. Función `agregarProducto()`
```javascript
function agregarProducto() {
    let select = document.getElementById("selectProducto");
    let idProducto = select.value;
    let nombreProducto = select.options[select.selectedIndex].text;
    let cantidad = parseInt(document.getElementById("inputCantidad").value);
    let precio = parseFloat(document.getElementById("inputPrecio").value);
    if (idProducto === "" || cantidad <= 0 || isNaN(precio)) {
        alert("Seleccioná un producto, cantidad válida y precio.");
        return;
    }
```
Este bloque constituye la primera etapa de la función `agregarProducto()`. Su propósito es extraer los valores ingresados por el usuario en los controles del formulario y validar que sean correctos antes de permitir que el artículo se añada a la tabla de venta.

#### Desglose completo del funcionamiento:

1. **Lectura del producto seleccionado (`selectProducto`):**
   * Obtiene el elemento desplegable del documento HTML y extrae dos datos distintos de la opción elegida por el usuario:
     * **`idProducto` (`select.value`):** Captura el identificador interno del producto (el valor oculto en el atributo `value`) que se enviará luego a la base de datos.
     * **`nombreProducto` (`select.options[select.selectedIndex].text`):** Accede al índice de la opción activa y extrae su texto visible para mostrar el nombre comercial del artículo en pantalla.

2. **Extracción y conversión de valores numéricos (`parseInt()` y `parseFloat()`):**
   * Debido a que los campos de entrada HTML devuelven siempre texto (*strings*), ambos valores se convierten a tipos numéricos para poder validar y calcular:
     * **`cantidad` (`parseInt`):** Convierte la cantidad ingresada a un número entero.
     * **`precio` (`parseFloat`):** Convierte el precio unitario a un número decimal para admitir centavos.

3. **Validación preventiva de integridad (`if (...)`):**
   * Evalúa tres condiciones de error simultáneamente mediante el operador lógico `||` (O) para evitar filas vacías o cálculos corruptos:
     * **`idProducto === ""`:** Comprueba que el usuario no haya dejado el selector en la opción por defecto sin elegir un artículo.
     * **`cantidad <= 0`:** Impide agregar cantidades nulas o negativas al carrito.
     * **`isNaN(precio)`:** Verifica si el campo de precio quedó vacío o contiene texto no numérico (*Not a Number*).

4. **Alerta al usuario y corte de ejecución (`alert()` y `return`):**
   * Si cualquiera de las validaciones falla, muestra una ventana emergente solicitando corregir los datos y ejecuta **`return`** para detener de inmediato la función, impidiendo que se cree la fila en la tabla.

#### Construcción de la Fila Dinámica
```javascript
    let subtotal = cantidad * precio;
    let tbody = document.getElementById("tablaDetalle");

    fila.innerHTML = `
        <td>${nombreProducto}<input type="hidden" name="id_producto[]" value="${idProducto}"></td>
```

Este bloque gestiona la interfaz del carrito de compras en el navegador. Permite agregar artículos a la tabla visual de la venta sin recargar la página y prepara internamente los datos ocultos necesarios para que PHP los procese al guardar el formulario.

#### Desglose completo del funcionamiento:

1. **Cálculo del subtotal por línea (`let subtotal = cantidad * precio`):**
   * Multiplica la cantidad seleccionada por el precio unitario del producto antes de construir la fila visual.

2. **Selección del contenedor y creación de fila (`getElementById` y `createElement("tr")`):**
   * Localiza el cuerpo de la tabla HTML (`tablaDetalle`) en el documento y crea en memoria un nuevo elemento de fila (`tr`) listo para recibir sus celdas.

3. **Construcción híbrida de celdas: vista + datos ocultos (`fila.innerHTML`):**
   * Rellena la fila con cinco columnas combinando texto legible para el usuario e campos invisibles (`input type="hidden"`) para el servidor:
     * **Arreglos paralelos para PHP (`id_producto[]`, `cantidad[]`, `precio[]`):** Los corchetes `[]` en el atributo `name` agrupan automáticamente los valores de todas las filas agregadas en listas ordenadas que PHP recibe al enviar el formulario.
     * **Formato monetario y atributos de datos (`toFixed(2)` y `data-subtotal`):** Muestra el precio y el subtotal redondeados a dos decimales para el usuario, mientras guarda el valor numérico exacto en el atributo `data-subtotal` para facilitar sumas posteriores en JavaScript.
     * **Botón de eliminación (`onclick="eliminarFila(this)"`):** Incluye un botón en la última celda que envía su propia referencia (`this`) para poder borrar esa fila específica si el usuario se equivoca.

4. **Inserción en pantalla (`tbody.appendChild(fila)`):**
   * Añade físicamente la fila recién construida al final de la tabla visible en el navegador.

5. **Actualización del total general (`calcularTotal()`):**

6. **Limpieza y reinicio de controles (`select.value`, `inputCantidad`, `inputPrecio`):**
   * Restablece el selector de productos a vacío, devuelve la cantidad por defecto a `1` y reinicia el precio a `0`, dejando el formulario limpio y listo para cargar el siguiente artículo.

### 4. Función `calcularTotal()`
```javascript
function calcularTotal() {
    let celdas = document.querySelectorAll(".subtotal-celda");
    let total = 0;
    celdas.forEach(function(celda) {
        total += parseFloat(celda.getAttribute("data-subtotal"));
    });
    document.getElementById("totalTexto").innerText = total.toFixed(2);
}
```
Esta función recorre todas las líneas de productos agregadas actualmente en la tabla del carrito para sumar sus importes parciales y actualizar en tiempo real el total general visible en la interfaz, sin necesidad de recargar la página.

#### Desglose completo del funcionamiento:

1. **Selección de todas las celdas de subtotal (`document.querySelectorAll(".subtotal-celda")`):**
   * Busca en todo el documento HTML los elementos de celda (`<td>`) marcados con la clase CSS `subtotal-celda` y los agrupa en una lista (`NodeList`) almacenada en la variable `celdas`.
   * Si la tabla está vacía o se acaban de eliminar todas las filas, la lista queda vacía y el cálculo resultante será automáticamente `0.00`.

2. **Inicialización del acumulador (`let total = 0`):**
   * Crea la variable numérica que acumulará la suma de la venta y la reinicia en cero cada vez que se ejecuta la función (al agregar o quitar un artículo) para evitar sumar valores duplicados.

3. **Recorrido y extracción de valores exactos (`forEach`, `getAttribute` y `parseFloat`):**
   * Itera sobre cada celda encontrada en la tabla y realiza tres acciones por fila:
     * **`celda.getAttribute("data-subtotal")`:** Lee el atributo personalizado HTML5 donde se guardó el valor numérico limpio del subtotal (evitando tener que limpiar símbolos de moneda como `$` o comas del texto visible).
     * **`parseFloat(...)`:** Convierte el valor leído del atributo (que HTML siempre entrega como texto) a un número decimal para mantener la precisión de los centavos.
     * **`total += ...`:** Suma el subtotal de esa línea al acumulador general.

4. **Actualización en pantalla con formato monetario (`innerText` y `toFixed(2)`):**
   * Localiza el elemento visual identificado como `totalTexto` y reemplaza su contenido con el resultado final redondeado siempre a exactamente dos decimales mediante **`toFixed(2)`**.
