# Explicación Exhaustiva y Completa de `logout.php`

Este archivo es el **módulo de cierre de sesión y desconexión segura** del sistema del *Taller de Pachi*.

A pesar de ser un archivo breve de apenas cuatro instrucciones, cumple una función crítica de **seguridad informática**: destruir por completo las credenciales del usuario en el servidor para evitar que otra persona que use la misma computadora pueda acceder a los datos privados del taller.

---

## Explicación Detallada Línea por Línea

A continuación se detalla cada instrucción, su significado técnico exacto y por qué es indispensable dentro del flujo del sistema.

---

### Línea 1: Apertura del Bloque de PHP
```php
<?php
```
* **¿Qué es?**: Es la etiqueta de apertura estándar de PHP.
* **¿Qué hace?**: Le indica al servidor web (como Apache o Nginx) que todo el texto que viene a continuación debe ser interpretado y procesado como código de programación en el servidor, y no enviado como texto plano al navegador.

---

### Línea 2: Reanudación de la Sesión Activa
```php
session_start();
```
* **¿Qué es?**: Función nativa de PHP que inicializa o reanuda una sesión existente.
* **¿Cómo funciona internamente?**: 
  1. Cuando un usuario navega por el sistema, el navegador envía una pequeña cookie identificadora llamada comúnmente `PHPSESSID`.
  2. Al invocar `session_start()`, PHP busca en el servidor el archivo de sesión asociado a esa cookie.
  3. Carga en la memoria del servidor los datos que se habían guardado al iniciar sesión (como `$_SESSION['id_usuario']` y `$_SESSION['nombre_usuario']`).
* **¿Por qué es obligatoria aquí?**: En PHP **no se puede destruir algo que no ha sido abierto primero**. Si no llamamos a `session_start()`, el servidor no sabe a qué usuario específico ni a qué archivo de sesión se quiere apuntar, por lo que la instrucción de destrucción fallaría o no tendría efecto.

---

### Línea 3: Destrucción de los Datos de Sesión
```php
session_destroy();
```
* **¿Qué es?**: Función nativa de PHP encargada de eliminar físicamente la información de la sesión.
* **¿Cómo funciona internamente?**:
  1. Borra el archivo temporal o el registro en memoria del servidor donde estaban almacenadas las variables del usuario.
  2. Al eliminar estos datos, las variables como `$_SESSION['id_usuario']` dejan de existir para las siguientes peticiones.
* **Impacto en la seguridad**: A partir del momento en que se ejecuta esta línea, cualquier intento posterior de ingresar a páginas como `index.php`, `ventas.php` o `productos.php` será interceptado por el archivo `verificarsesion.php`, ya que al evaluar `isset($_SESSION['id_usuario'])`, el resultado será falso y el sistema considerará al usuario como un visitante no autorizado.

---

### Línea 4: Redirección al Inicio de Sesión
```php
header("Location: login.php");
```
* **¿Qué es?**: Función de PHP que envía una cabecera de protocolo HTTP sin procesar (*raw HTTP header*) directamente al navegador web del cliente.
* **¿Qué significa `Location: login.php`?**:
  * Es una instrucción estándar de la web que emite un código de estado de redirección (comúnmente HTTP `302 Found`).
  * Le da una orden directa al navegador del usuario diciendo: *"Esta página terminó su trabajo, cambia de dirección inmediatamente y carga `login.php`"*.
* **Efecto visual**: El usuario hace clic en el botón "Salir" del menú y, de forma instantánea y transparente, su pantalla cambia llevándolo al formulario de acceso.

---

### Línea 5: Detención Absoluta del Script
```php
exit();
```
* **¿Qué es?**: Función de PHP (equivalente a `die()`) que finaliza y cancela de manera inmediata la ejecución del script actual.
* **¿Por qué es indispensable por seguridad?**:
  * Cuando se ejecuta la función `header()`, la orden de redirección se envía al navegador, pero **el intérprete de PHP sigue corriendo en el servidor** procesando cualquier línea que esté escrita más abajo.
  * Si un atacante o una herramienta automatizada manipula las cabeceras para ignorar la redirección, el servidor podría seguir ejecutando código si no colocamos `exit()`.
  * Al escribir `exit()`, nos aseguramos de que el servidor corte el hilo de ejecución en ese microsegundo exacto, garantizando que no se procese absolutamente nada más.

---

### Línea 6: Cierre del Bloque de PHP
```php
?>
```
* **¿Qué es?**: La etiqueta de cierre de PHP.
* **¿Qué hace?**: Marca el final del código PHP para el intérprete del servidor.

---

## Resumen del Ciclo de Funcionamiento

Cuando un empleado o administrador hace clic en el botón **"Salir"** ubicado en la barra de navegación (`navbar.php`), se desencadena la siguiente secuencia precisa:

1. El navegador hace una petición web hacia `logout.php`.
2. `session_start()` ubica al usuario en el servidor.
3. `session_destroy()` elimina sus permisos y credenciales activas del servidor.
4. `header("Location: login.php")` ordena al navegador volver a la pantalla de login.
5. `exit()` apaga el proceso en el servidor.
6. El navegador muestra la pantalla de inicio de sesión con el acceso nuevamente bloqueado.
