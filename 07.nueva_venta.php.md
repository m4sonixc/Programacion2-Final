# Explicación Detallada y Completa de `nueva_venta.php`

Este archivo es el **módulo de creación de ventas** del sistema del *Taller de Pachi*. 

Es uno de los archivos más completos e importantes del sistema, ya que combina tres capas de programación:
1. **PHP (Servidor):** Procesa el guardado en la base de datos mediante transacciones seguras, calcula el total y descuenta automáticamente los productos del inventario (stock).
2. **HTML5 y Bootstrap 5 (Diseño):** Presenta una interfaz organizada en dos secciones (cabecera con cliente/vendedor y detalle con selector de artículos).
3. **JavaScript (Navegador):** Permite agregar productos de forma dinámica a una tabla en tiempo real, cargar precios automáticamente, quitar productos y calcular subtotales y totales sin necesidad de recargar la página.

## SECCIÓN 1: Código PHP (Lógica del Servidor)

El archivo comienza ejecutando código en el servidor antes de mostrar cualquier elemento visual.

### 1. Inclusión de Módulos Base
```php

```
* **`verificarsesion.php`**: Verifica que el usuario tenga una sesión abierta. Si no está logueado, lo expulsa al login de inmediato.

### 2. Procesamiento del Formulario al Guardar la Venta (`POST`)
```php
$error = "";
if ($_SERVER["REQUEST_METHOD"] == "POST") {
```
**`$_SERVER`:** Variable superglobal de PHP que contiene información sobre el entorno del servidor y los detalles de la petición HTTP actual.
* **`"REQUEST_METHOD"`:** Índice que identifica el método utilizado por el navegador para solicitar la página (por ejemplo, `GET` al entrar normalmente o `POST` al enviar un formulario).
* **`== "POST"`:** Condición que asegura que el bloque de código interno solo se ejecute cuando el usuario haya enviado los datos del formulario, evitando errores o validaciones vacías al cargar la página por primera vez.
* **`$error = ""`**: Variable inicializada en vacío para guardar cualquier mensaje de error que pueda ocurrir.
* **`if ($_SERVER["REQUEST_METHOD"] == "POST")`**: Comprueba si el usuario presionó el botón final "Guardar Venta".

```php
    $id_cliente = intval($_POST["id_cliente"] ?? 0);
```

* **`$productos_ids`**: Arreglo con los IDs de todos los productos agregados a la lista.

* **`$precios`**: Arreglo con el precio unitario pactado para cada producto.
* **`?? []` / `?? 0`**: Operadores de seguridad por si algún dato no fue enviado.

### 5. Cálculo del Total de la Venta en el Servidor
```php
        $total_venta = 0;
        for ($i = 0; $i < count($productos_ids); $i++) {
            $total_venta += intval($cantidades[$i]) * floatval($precios[$i]);
        }
```
Este bloque calcula el importe final de una venta recorriendo de forma sincronizada los arreglos paralelos recibidos desde el formulario (productos, cantidades y precios).

#### Desglose del funcionamiento:

1. **Inicialización del acumulador (`$total_venta = 0`):** Crea la variable que almacenará la suma final y la establece en cero antes de comenzar el recorrido para evitar valores residuales o errores matemáticos.
2. **Recorrido de arreglos paralelos (`for` y `count($productos_ids)`):** Inicia un ciclo controlado por el índice `$i` desde `0` hasta la cantidad total de productos seleccionados. Como los datos del carrito llegan en listas separadas pero ordenadas por posición, el mismo índice `$i` permite acceder simultáneamente al producto, la cantidad y el precio de una misma fila.
3. **Conversión segura de tipos (`intval()` y `floatval()`):** Dado que los datos enviados por formularios HTML llegan como cadenas de texto (*strings*), se fuerza su conversión antes de operar:
   * **`intval($cantidades[$i])`:** Convierte la cantidad a un número entero.
   * **`floatval($precios[$i])`:** Convierte el precio unitario a un número decimal (punto flotante) para conservar los centavos.
4. **Cálculo de subtotal y acumulación (`+=`):** En cada vuelta multiplica la cantidad por el precio unitario de ese artículo y suma el resultado directamente al valor acumulado en `$total_venta`.

### 6. Transacción en Base de Datos (Guardado Seguro y Descuento de Stock)
```php
        $conexion->beginTransaction();
        try {
```
* **`$conexion->beginTransaction()`**: Inicia una transacción. Le ordena a MySQL que todas las operaciones siguientes se ejecuten en bloque como una unidad indivisible.

#### A. Guardar la Cabecera de la Venta
```php
            $stmt_cab = $conexion->prepare("INSERT INTO ventas (id_cliente, id_usuario, total) VALUES (?, ?, ?)");
            $stmt_cab->execute([$id_cliente, $id_usuario, $total_venta]);
            $id_venta = $conexion->lastInsertId();
```
Este bloque inserta el registro principal de una venta en la base de datos y recupera su identificador único en tres pasos:

1. **Preparación de la consulta (`$conexion->prepare(...)`):** Define la sentencia SQL `INSERT INTO ventas` utilizando marcadores de posición (`?`) para los campos `id_cliente`, `id_usuario` y `total`. Esto separa la estructura de la consulta de los datos, evitando ataques de inyección SQL.
2. **Ejecución con parámetros (`$stmt_cab->execute([...])`):** Ejecuta la consulta preparada asignando en orden los valores reales (`$id_cliente`, `$id_usuario` y `$total_venta`) a cada marcador `?`.
3. **Obtención del ID generado (`$conexion->lastInsertId()`):** Recupera el valor autoincremental (clave primaria) que la base de datos asignó a esta nueva venta y lo guarda en `$id_venta` para poder vincularlo posteriormente con los productos del detalle de venta.

#### B. Guardar los Detalles y Descontar el Stock
```php
            $stmt_det = $conexion->prepare("INSERT INTO detalle_ventas (id_venta, id_producto, cantidad, precio_unitario, subtotal) VALUES (?, ?, ?, ?, ?)");
            $stmt_stock = $conexion->prepare("UPDATE productos SET stock = stock - ? WHERE id_producto = ?");
            for ($i = 0; $i < count($productos_ids); $i++) {
                $id_prod = intval($productos_ids[$i]);
                $cant = intval($cantidades[$i]);
                $prec = floatval($precios[$i]);
                $sub = $cant * $prec;
                $stmt_det->execute([$id_venta, $id_prod, $cant, $prec, $sub]);
                $stmt_stock->execute([$cant, $id_prod]);
            }
```
Este bloque procesa cada producto incluido en la venta, guarda su registro individual y descuenta automáticamente las unidades vendidas del inventario siguiendo estos pasos:

1. **Preparación de consultas (`prepare`):** Antes de iniciar el ciclo, se dejan listas dos sentencias SQL parametrizadas (usando marcadores `?`) para optimizar el rendimiento y evitar inyecciones SQL:
   * **`$stmt_det`:** Inserta cada línea de producto en la tabla `detalle_ventas`.
   * **`$stmt_stock`:** Resta la cantidad vendida al stock actual del producto en la tabla `productos`.
2. **Recorrido de productos (`for`):** Itera sobre los arreglos paralelos (`$productos_ids`, `$cantidades` y `$precios`) según la cantidad total de artículos incluidos en la venta.
3. **Conversión de tipos y cálculo (`intval` / `floatval`):** Asegura que el ID y la cantidad sean números enteros y el precio un número decimal, calculando el subtotal de la línea (`$sub = $cant * $prec`).
4. **Ejecución sincronizada (`execute`):** Por cada producto del ciclo, ejecuta primero la inserción en el detalle de la venta vinculada al `$id_venta` y, acto seguido, ejecuta la actualización que descuenta esa cantidad del inventario.


#### C. Confirmación o Cancelación (Commit / Rollback)
```php
            $conexion->commit();
            header("Location: ver_venta.php?id=" . $id_venta);
            exit();
        } catch (Exception $e) {
            $conexion->rollBack();
            $error = "Ocurrió un error al guardar la venta.";
        }
```
Este bloque garantiza la integridad de los datos al guardar una venta utilizando una transacción de base de datos y un bloque `try-catch`:

1. **Confirmación de cambios (`$conexion->commit()`):** Si todas las consultas previas (como registrar la venta y descontar el stock) se ejecutaron sin fallos, confirma y guarda los cambios de forma permanente en la base de datos.
2. **Redirección con parámetro (`header(...)` y `exit()`):** Una vez guardada la venta, redirige al usuario a `ver_venta.php` enviando el identificador de la operación (`$id_venta`) por la URL y detiene inmediatamente la ejecución del script.
3. **Captura de errores (`catch (Exception $e)`):** Intercepta cualquier fallo o excepción técnica que ocurra durante el proceso de guardado para evitar que el sistema se detenga de forma abrupta.
4. **Reversión de cambios (`$conexion->rollBack()`):** Si ocurre algún error antes del `commit()`, deshace todas las operaciones realizadas en la base de datos durante esa transacción, evitando registros incompletos o inconsistencias en el inventario.
5. **Notificación al usuario (`$error`):** Asigna un mensaje controlado (`"Ocurrió un error al guardar la venta."`) para mostrarlo en la interfaz sin exponer detalles internos del servidor.

## SECCIÓN 3: Código JavaScript (Interactividad en el Navegador)

Este bloque de script corre dentro del navegador del usuario sin consultar al servidor en cada clic.

### 1. Función `cargarPrecio()`
```javascript
function cargarPrecio() {
    let select = document.getElementById("selectProducto");
    let opcion = select.options[select.selectedIndex];
    document.getElementById("inputPrecio").value = opcion.getAttribute("data-precio");
}
```
Esta función se encarga de autocompletar automáticamente el campo del precio unitario en el formulario de ventas cada vez que el usuario selecciona un producto de la lista desplegable, evitando errores de carga manual.

#### Desglose del funcionamiento:

1. **Captura del selector (`document.getElementById("selectProducto")`):** Obtiene la referencia del elemento HTML `<select>` que contiene el listado de productos disponibles y la guarda en la variable `select`.
2. **Identificación de la opción elegida (`select.options[select.selectedIndex]`):** Accede a la lista interna de opciones del desplegable utilizando el índice de la posición actualmente marcada por el usuario (`selectedIndex`), guardando esa etiqueta `<option>` específica en `opcion`.
3. **Lectura del atributo personalizado (`opcion.getAttribute("data-precio")`):** Extrae el valor almacenado en el atributo HTML `data-precio` de la opción seleccionada (donde PHP imprimió previamente el precio del producto desde la base de datos).
4. **Asignación automática (`document.getElementById("inputPrecio").value = ...`):** Inserta el precio extraído directamente dentro de la caja de texto del precio (`inputPrecio`), dejándolo listo para calcular subtotales o agregarlo al carrito.

---

### Lógica de Funcionamiento (`cargarPrecio`)

La función se encarga de actualizar automáticamente el campo de precio en un formulario cuando el usuario elige un producto:

1. **Captura del selector:** Obtiene la referencia de la lista desplegable de productos (`selectProducto`) y la guarda en la variable `select`.
2. **Identificación de la opción elegida:** Localiza y almacena en `opcion` la etiqueta `<option>` que está actualmente seleccionada por el usuario.
3. **Asignación del precio:** Lee el valor del atributo `data-precio` de esa opción y lo inserta directamente dentro del campo de texto o número (`inputPrecio`) mediante su propiedad `.value`.

### 2. Función `agregarProducto()`
```javascript
function agregarProducto() {
    let select = document.getElementById("selectProducto");

        return;
    }
```
Esta función se ejecuta en el navegador del cliente al intentar añadir un artículo a la lista de venta. Su objetivo es capturar los valores ingresados en el formulario y validar que sean correctos antes de agregarlos visualmente a la tabla o enviarlos al servidor.

#### Desglose del funcionamiento:

1. **Captura del producto seleccionado (`selectProducto`):** Obtiene la referencia al menú desplegable del HTML y extrae dos datos distintos de la opción elegida:
   * **`idProducto` (`select.value`):** Captura el identificador interno oculto del artículo (el ID de la base de datos).
   * **`nombreProducto` (`select.options[select.selectedIndex].text`):** Accede al índice de la opción marcada actualmente y extrae el texto visible que lee el usuario (el nombre del producto).
2. **Lectura y conversión numérica (`parseInt` y `parseFloat`):** Recupera lo escrito en los campos de texto y los transforma a formatos matemáticos operables:
   * **`cantidad` (`parseInt(...)`):** Convierte el valor de `inputCantidad` a un número entero.
   * **`precio` (`parseFloat(...)`):** Convierte el valor de `inputPrecio` a un número decimal para respetar los centavos.
3. **Validación preventiva (`if (...)`):** Evalúa tres condiciones de error antes de continuar: que no se haya elegido ningún producto (`idProducto === ""`), que la cantidad sea cero o negativa (`cantidad <= 0`) o que el precio no sea un número válido (`isNaN(precio)`).
4. **Alerta y corte de ejecución (`alert` y `return`):** Si cualquiera de las validaciones falla, muestra una ventana emergente avisando al usuario qué debe corregir y ejecuta `return;` para detener inmediatamente la función, evitando que se carguen filas vacías o corruptas en la venta.


#### Inserción de la Fila con Inputs Ocultos
```javascript
    let subtotal = cantidad * precio;
    let tbody = document.getElementById("tablaDetalle");
    let fila = document.createElement("tr");
    fila.innerHTML = `
        <td>${nombreProducto}<input type="hidden" name="id_producto[]" value="${idProducto}"></td>
        <td>${cantidad}<input type="hidden" name="cantidad[]" value="${cantidad}"></td>
        <td>$${precio.toFixed(2)}<input type="hidden" name="precio[]" value="${precio}"></td>
        <td class="subtotal-celda" data-subtotal="${subtotal}">$${subtotal.toFixed(2)}</td>
        <td><button type="button" class="btn btn-danger btn-sm" onclick="eliminarFila(this)">Quitar</button></td>
    `;
    
```
Este bloque de JavaScript se encarga de agregar visualmente un producto al carrito o detalle de venta dentro de la interfaz web sin recargar la página. Al mismo tiempo, prepara los datos de forma oculta para que, cuando se envíe el formulario completo, el servidor en PHP pueda recibir todos los artículos como arreglos paralelos listos para guardar en la base de datos.

#### Desglose detallado del funcionamiento:

1. **Cálculo del importe parcial (`let subtotal = cantidad * precio`):**
   Multiplica la cantidad de unidades seleccionadas por el precio unitario del producto. El resultado se guarda en memoria como un valor numérico puro (`subtotal`) antes de aplicarle formato de moneda, lo que permite reutilizarlo tanto para mostrarlo en pantalla como para cálculos matemáticos posteriores en el navegador.

2. **Selección del cuerpo de la tabla en el DOM (`document.getElementById("tablaDetalle")`):**
   Busca en el documento HTML el elemento contenedor identificado con el ID `tablaDetalle` (habitualmente la etiqueta `<tbody>` de la tabla de ventas) y guarda su referencia en la variable `tbody` para poder insertar nuevas filas en su interior.

3. **Creación de un nodo de fila en memoria (`document.createElement("tr")`):**
   Genera dinámicamente una nueva etiqueta de fila de tabla (`<tr>`) en la memoria del navegador. En este punto la fila todavía no es visible para el usuario; primero se construye toda su estructura interna antes de incorporarla definitivamente a la tabla.

4. **Inyección de columnas mediante plantillas literales (`fila.innerHTML = \`...\``):**
   Utiliza comillas invertidas (*template literals*) e interpolación de variables (`${...}`) para construir cinco celdas (`<td>`) en una sola operación. Este diseño separa inteligentemente lo que el usuario ve en pantalla de los datos crudos que viajarán al servidor mediante campos ocultos (`<input type="hidden">`) cuyos nombres terminan en corchetes (`[]`) para que PHP los agrupe automáticamente como listas ordenadas:
   * **Primera celda (Producto e identificador oculto):** Muestra el nombre legible del artículo (`nombreProducto`) para el operador, mientras incrusta un campo oculto con `name="id_producto[]"` y el valor real de su clave primaria (`idProducto`). De este modo, el usuario lee texto comprensible pero el servidor recibe el ID exacto de la base de datos.
   * **Segunda celda (Cantidad solicitada):** Imprime visualmente la cantidad elegida y la acompaña con un campo oculto `name="cantidad[]"`. Al mantener el mismo orden de creación que los productos, ambos arreglos quedan sincronizados por posición (índice).
   * **Tercera celda (Precio unitario formateado vs. valor crudo):** Utiliza el método `.toFixed(2)` acompañado del signo `$` para mostrar el precio siempre con dos decimales (por ejemplo, `$1500.00`). Sin embargo, dentro del campo oculto `name="precio[]"` guarda el número sin signo de moneda ni formato visual, evitando errores de conversión cuando PHP procese el dato con `floatval()`.
   * **Cuarta celda (Subtotal y atributo personalizado `data-subtotal`):** Presenta el subtotal formateado al usuario (`$${subtotal.toFixed(2)}`), pero añade la clase CSS `subtotal-celda` y el atributo estándar de HTML5 `data-subtotal="${subtotal}"`. Esto permite que otras funciones de JavaScript recorran todas las celdas de subtotal y lean el número exacto directamente desde el atributo `data-subtotal` para recalcular el total general de la venta, sin tener que limpiar símbolos de moneda del texto visible.
   * **Quinta celda (Botón de eliminación de fila):** Inserta un botón estilizado con clases de Bootstrap (`btn btn-danger btn-sm`). Incluye explícitamente el atributo `type="button"` para evitar que al hacer clic se envíe por accidente el formulario HTML completo (ya que el comportamiento por defecto de un `<button>` dentro de un `<form>` es actuar como `submit`). Además, pasa la palabra clave `this` a la función `onclick="eliminarFila(this)"`, enviando una referencia directa al propio botón pulsado para que JavaScript pueda localizar su fila padre (`<tr>`) y eliminar únicamente ese artículo.

#### Conexión entre el Frontend (JavaScript) y el Backend (PHP):

Cada fila generada por este fragmento construye el paquete de datos que viajará por método `POST` al guardar la venta. Al enviar el formulario, PHP recibirá tres arreglos paralelos (`$_POST["id_producto"]`, `$_POST["cantidad"]` y `$_POST["precio"]`) con exactamente la misma longitud y orden, permitiendo que el servidor recorra todas las líneas con un ciclo `for`, calcule el total final de forma segura y registre cada artículo en la tabla `detalle_ventas`.

#### Limpieza de los Campos de Entrada
```javascript
    tbody.appendChild(fila);
    calcularTotal();
    select.value = "";
    document.getElementById("inputCantidad").value = 1;
    document.getElementById("inputPrecio").value = 0;
}
```
Este bloque representa la etapa final de la función encargada de agregar un producto al detalle de venta en el navegador (del lado del cliente). Su propósito es renderizar visualmente el nuevo artículo dentro de la tabla del carrito, actualizar los importes acumulados en tiempo real y restaurar los campos del formulario a su estado inicial para agilizar la carga del siguiente ítem.

#### Desglose detallado del funcionamiento:

1. **Inyección de la fila en el DOM (`tbody.appendChild(fila)`):**
   * **Manipulación del árbol HTML (DOM):** Toma el nodo HTML previamente construido en memoria (un elemento de fila `<tr>` almacenado en la variable `fila`, que contiene las celdas `<td>` con el nombre, cantidad, precio, subtotal, botón de eliminar y los campos ocultos `input type="hidden"` con arreglos como `productos[]` y `cantidades[]`) y lo inserta como el último hijo dentro del cuerpo de la tabla (`<tbody>`).
   * **Impacto en el envío de datos:** Al quedar adjuntada dentro del formulario en el DOM, la fila deja de existir solo en la memoria de JavaScript y pasa a formar parte oficial de los datos que se enviarán al servidor por método `POST` al confirmar la venta.

2. **Recálculo dinámico de totales (`calcularTotal()`):**
   * **Sincronización financiera:** Invoca inmediatamente a la función auxiliar encargada de recorrer todas las filas activas que se encuentran en ese momento dentro del `tbody`.
   * **Actualización de interfaz:** Suma los subtotales de cada artículo listado y actualiza tanto el indicador visual en pantalla (por ejemplo, una etiqueta `<span>` o `<div>` que muestra el total al cajero) como cualquier campo oculto destinado a transportar el monto general, garantizando que el importe refleje exactamente el nuevo producto recién incorporado.

3. **Reinicio del selector de productos (`select.value = ""`):**
   * **Limpieza de selección:** Restablece el valor de la lista desplegable (`<select>`) a una cadena vacía (`""`), lo que obliga al control a volver a su opción predeterminada o marcador de posición (como *"Seleccione un producto..."*). Esto evita que el usuario agregue por error el mismo artículo dos veces seguidas al hacer clic accidentalmente.

4. **Restablecimiento de la cantidad predeterminada (`document.getElementById("inputCantidad").value = 1`):**
   * **Optimización de experiencia de usuario (UX):** Localiza en el documento el campo numérico de cantidad mediante su identificador único (`id="inputCantidad"`) y sobrescribe su propiedad `.value` con el número `1`. Se establece en `1` y no en `0` porque, en un flujo de punto de venta, la unidad mínima lógica para una próxima carga siempre es al menos un artículo, ahorrando pulsaciones de teclado al operador.

5. **Limpieza del campo de precio unitario (`document.getElementById("inputPrecio").value = 0`):**
   * **Prevención de datos residuales:** Busca el campo correspondiente al precio (`id="inputPrecio"`) y lo devuelve a `0`. De este modo se elimina el costo del producto anterior de la vista y se evita que quede un precio desactualizado visible mientras no haya ningún otro artículo seleccionado en el desplegable.

6. **Cierre del bloque de función (`}`):**
   * Marca el fin de la ejecución de la rutina de inserción en el carrito, dejando la interfaz limpia, sincronizada y lista para recibir un nuevo evento del usuario o procesar el envío definitivo del formulario hacia el backend en PHP.

### 3. Función `eliminarFila(boton)`
```javascript
function eliminarFila(boton) {
    boton.closest("tr").remove();
    calcularTotal();
}
```
Esta función permite quitar un producto de la tabla visual de ventas en tiempo real (del lado del cliente) y actualizar inmediatamente el importe final sin necesidad de recargar la página.

#### Desglose del funcionamiento:

1. **Recepción del disparador (`function eliminarFila(boton)`):** Recibe como parámetro la referencia exacta del botón HTML (`boton`) sobre el cual el usuario hizo clic.
2. **Búsqueda de la fila contenedora (`boton.closest("tr")`):** Navega hacia arriba en la estructura del documento (DOM) a partir del botón presionado hasta encontrar la etiqueta de fila de tabla (`<tr>`) más cercana que lo contiene.
3. **Eliminación del elemento (`.remove()`):** Borra por completo esa fila `<tr>` (junto con todas sus celdas e inputs ocultos) de la interfaz gráfica, quitando el artículo de la lista de compra.
4. **Recálculo automático (`calcularTotal()`):** Invoca inmediatamente a la función encargada de sumar los subtotales restantes para que el monto total mostrado en pantalla refleje la resta del producto eliminado.

### 4. Función `calcularTotal()`
```javascript
function calcularTotal() {
    let celdas = document.querySelectorAll(".subtotal-celda");
    let total = 0;
    celdas.forEach(function(celda) {
        total += parseFloat(celda.getAttribute("data-subtotal"));
    });
    document.getElementById("totalTexto").innerText = total.toFixed(2);
}
```
### Conceptos Clave

* **`document.querySelectorAll(".subtotal-celda")`:** Selecciona todos los elementos del DOM (como celdas de una tabla) que tengan la clase CSS `subtotal-celda`, devolviendo una lista de nodos.
* **`let total = 0`:** Inicializa una variable acumuladora en cero donde se irá sumando el importe de cada fila.
* **`forEach(...)`:** Recorre uno por uno cada elemento encontrado en la lista `celdas`.
* **`getAttribute("data-subtotal")`:** Extrae el valor numérico limpio almacenado en el atributo personalizado `data-subtotal` de cada celda, evitando problemas con símbolos de moneda o formatos visuales.
* **`parseFloat(...)`:** Convierte el texto extraído del atributo HTML en un número decimal operatable para poder sumarlo matemáticamente.
* **`toFixed(2)`:** Formatea el resultado final redondeándolo a exactamente **dos decimales** (por ejemplo, `150.5` pasa a `"150.50"`).
* **`document.getElementById("totalTexto").innerText`:** Busca el elemento HTML con el identificador `totalTexto` y actualiza su contenido visible en pantalla con el monto total calculado.

---

### Flujo de Ejecución

1. **Captura de subtotales:** Obtiene todas las celdas de subtotales presentes en la tabla.
2. **Acumulación:** Recorre cada celda, extrae su valor numérico desde `data-subtotal`, lo convierte a decimal y lo suma a la variable `total`.
3. **Renderizado en pantalla:** Formatea el monto acumulado a dos decimales y lo muestra dentro del elemento `totalTexto`.
