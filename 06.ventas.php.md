# Explicación Detallada y Completa de `ventas.php`

Este archivo es el **módulo principal de gestión de ventas** del sistema del *Taller de Pachi*. Cumple tres funciones centrales:
1. **Seguridad:** Verifica que solo usuarios autenticados puedan ingresar.
2. **Eliminación inteligente de ventas:** Si se solicita borrar una venta, no solo la elimina, sino que devuelve automáticamente los productos al inventario (restaura el stock) usando transacciones seguras.
3. **Listado visual:** Muestra en una tabla moderna todas las ventas registradas con sus datos más importantes (fecha, cliente, vendedor, monto total y botones de acción).

---

## PARTE 1: El Código PHP (Lógica del Servidor)

El archivo comienza con un bloque de PHP que se ejecuta en el servidor antes de enviar cualquier elemento visual al navegador.

### 1. Inclusión de Archivos y Seguridad Inicial
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Llama al archivo de seguridad. Si el usuario no inició sesión, este archivo detiene todo y lo expulsa al `login.php`. El `require_once` asegura que se cargue una única vez y que, si el archivo falta, el sistema no continúe por seguridad.
* **`require_once "config/conexion.php";`**: Trae la conexión a la base de datos MySQL mediante el objeto `$conexion` (PDO).

---

### 2. Variables para Avisos al Usuario
```php
$mensaje = "";
$tipo_alerta = "";
```
* **`$mensaje`**: Variable vacía que guardará el texto que se le mostrará al usuario (por ejemplo: *"Venta eliminada correctamente"*).
* **`$tipo_alerta`**: Guardará la clase de estilo para el aviso (por ejemplo `"success"` para color verde o `"danger"` para color rojo).

---

### 3. Proceso Completo de Eliminación de Venta (Con Restauración de Stock)
Este bloque solo se activa si en la dirección web (URL) viene el parámetro `eliminar` (por ejemplo: `ventas.php?eliminar=5`).

```php
if (isset($_GET["eliminar"])) {
    $id_venta = intval($_GET["eliminar"]);
```
* **`if (isset($_GET["eliminar"]))`**: Pregunta si se hizo clic en el botón de eliminar de alguna venta.
* **`intval($_GET["eliminar"])`**: Toma el valor recibido por la URL y lo convierte estrictamente a un número entero. Esto evita que alguien intente pasar texto malicioso o inyecciones por la URL.

#### Inicio de la Transacción en la Base de Datos
```php
    $conexion->beginTransaction();
    try {
```
* **`$conexion->beginTransaction();`**: Abre una **transacción**. Una transacción es un mecanismo de seguridad donde se le dice a la base de datos: *"Voy a hacer varios cambios juntos. Si todos salen bien, guárdalos; pero si falla aunque sea uno solo, cancela todo y déjalo como estaba antes"*. Esto evita que se borre la venta pero no se recupere el stock.
* **`try { ... }`**: Bloque de prueba donde se intentan realizar las operaciones.

#### Paso A: Consultar qué productos se vendieron en esa venta
```php
        $stmt_det = $conexion->prepare("SELECT id_producto, cantidad FROM detalle_ventas WHERE id_venta = ?");
        $stmt_det->execute([$id_venta]);
        $items = $stmt_det->fetchAll();
```
* Busca en la tabla `detalle_ventas` todos los artículos asociados a esa venta específica y qué cantidad se llevó el cliente.
* **`$items`**: Arreglo que contiene la lista de esos productos con sus cantidades.

#### Paso B: Devolver el stock a cada producto
```php
        $stmt_stock = $conexion->prepare("UPDATE productos SET stock = stock + ? WHERE id_producto = ?");
        foreach ($items as $item) {
            $stmt_stock->execute([$item["cantidad"], $item["id_producto"]]);
        }
```
* Prepara la consulta para sumar (`stock = stock + ?`) la cantidad que se había restado al momento de vender.
* **`foreach ($items as $item)`**: Recorre uno por uno los productos comprados y ejecuta la suma en la tabla `productos`. Así, el inventario vuelve a estar completo.

#### Paso C: Eliminar los detalles y la venta
```php
        $stmt_del_det = $conexion->prepare("DELETE FROM detalle_ventas WHERE id_venta = ?");
        $stmt_del_det->execute([$id_venta]);

        $stmt_del_venta = $conexion->prepare("DELETE FROM ventas WHERE id_venta = ?");
        $stmt_del_venta->execute([$id_venta]);
```
* Primero borra los registros de `detalle_ventas` asociados a esa venta.
* Luego borra el registro principal de la tabla `ventas`.
* *(Se hace en este orden estricto para no romper las reglas de claves foráneas de la base de datos).*

#### Paso D: Confirmación del éxito
```php
        $conexion->commit();
        $mensaje = "Venta #$id_venta eliminada correctamente y stock restaurado.";
        $tipo_alerta = "success";
    }
```
* **`$conexion->commit();`**: Confirma la transacción y hace permanentes todos los cambios en la base de datos (el stock sumado y los registros borrados).
* Se define el mensaje de éxito y el color verde (`success`).

#### Paso E: Manejo de fallos (Rollback)
```php
    } catch (Exception $e) {
        $conexion->rollBack();
        $mensaje = "Error al eliminar la venta.";
        $tipo_alerta = "danger";
    }
}
```
* Si ocurre cualquier problema técnico durante el proceso, el bloque `catch` atrapa el error.
* **`$conexion->rollBack();`**: Deshace absolutamente todo lo que se haya hecho en ese intento. No se descuenta ni se borra nada, protegiendo la integridad de la base de datos.
* Se define el mensaje de error y el color rojo (`danger`).

---

### 4. Consulta para Listar Todas las Ventas
```php
$sql_ventas = "SELECT v.id_venta, v.fecha, v.total, 
                      c.nombre AS cli_nombre, c.apellido AS cli_apellido,
                      u.nombre AS vendedor
               FROM ventas v
               INNER JOIN clientes c ON v.id_cliente = c.id_cliente
               INNER JOIN usuarios u ON v.id_usuario = u.id_usuario
               ORDER BY v.id_venta DESC";
$ventas = $conexion->query($sql_ventas)->fetchAll();
```
* **`SELECT`**: Elige los campos a mostrar: número de venta (`id_venta`), fecha, total, el nombre y apellido del cliente, y el nombre del usuario que realizó la venta (vendedor).
* **`INNER JOIN clientes`**: Une la tabla de ventas con la tabla de clientes mediante el campo común `id_cliente` para saber a quién se le vendió.
* **`INNER JOIN usuarios`**: Une la tabla de ventas con la de usuarios mediante `id_usuario` para saber qué empleado atendió la venta.
* **`ORDER BY v.id_venta DESC`**: Ordena las ventas de forma descendente (de mayor a menor ID), haciendo que la última venta realizada aparezca primera en la lista.
* **`fetchAll()`**: Guarda todas las filas encontradas dentro de la variable `$ventas`.

## PARTE 2: El Código HTML y la Interfaz Visual

A partir del cierre de PHP, se genera el documento que ve el usuario en su pantalla.

### 1. Cabecera HTML y Recursos
```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ventas - Taller de Pachi</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
```
* **`<!DOCTYPE html>`** y **`<html lang="es">`**: Declara un documento HTML5 en idioma español.
* **`charset="UTF-8"`**: Permite visualizar correctamente acentos, letras ñ y caracteres especiales.
* **`viewport`**: Hace que la página sea responsiva y se adapte al tamaño de teléfonos, tablets o computadoras.
* **`link bootstrap`**: Carga los estilos visuales de Bootstrap 5 desde internet.

---

### 2. Cuerpo de la Página y Menú Superior
```html
<body class="bg-light">
    <?php include "navbar.php"; ?>
    <div class="container">
```
* **`class="bg-light"`**: Pone un color de fondo gris claro para dar sensación de pulcritud.
* **`<?php include "navbar.php"; ?>`**: Inserta la barra de navegación superior que contiene los enlaces a las otras secciones del sistema.
* **`container`**: Contenedor principal de Bootstrap que centra el contenido en la pantalla y deja márgenes ordenados a los lados.

---

### 3. Título y Botón para Registrar Ventas
```html
        <div class="d-flex justify-content-between align-items-center mb-4">
            <h3>Gestión de Ventas</h3>
            <a href="nueva_venta.php" class="btn btn-primary">+ Nueva Venta</a>
        </div>
```
* **`d-flex justify-content-between align-items-center`**: Utiliza Flexbox para colocar el título a la izquierda y el botón a la derecha, alineados a la misma altura.
* **`mb-4`**: Margen inferior para separar esta cabecera de la tabla.
* **`btn btn-primary`**: Botón azul destacado que lleva al formulario de creación (`nueva_venta.php`).

---

### 4. Mensaje Dinámico de Alerta (Éxito o Error)
```php
        <?php if ($mensaje != ""): ?>
            <div class="alert alert-<?php echo $tipo_alerta; ?> alert-dismissible fade show">
                <?php echo $mensaje; ?>
                <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
            </div>
        <?php endif; ?>
```
* Si la variable `$mensaje` no está vacía (porque se acaba de eliminar una venta o hubo un error), se genera este cuadro de aviso.
* **`alert-<?php echo $tipo_alerta; ?>`**: Si salió bien, imprime `alert-success` (fondo verde); si falló, imprime `alert-danger` (fondo rojo).
* **`btn-close` y `data-bs-dismiss="alert"`**: Agrega una "X" pequeña a la derecha para que el usuario pueda cerrar el cartel cuando quiera.

---

### 5. Tarjeta Contenedora y Tabla de Datos
```html
        <div class="card shadow-sm">
            <div class="card-body p-0 table-responsive">
                <table class="table table-striped table-hover mb-0">
```
* **`card shadow-sm`**: Encierra la tabla dentro de una tarjeta blanca con bordes redondeados y una sombra suave.
* **`p-0`**: Elimina el relleno interno para que la tabla llegue hasta los bordes de la tarjeta.
* **`table-responsive`**: Si la pantalla es muy chica (un celular), permite deslizar la tabla hacia los lados con el dedo sin romper el diseño de la pantalla.
* **`table-striped`**: Pinta una fila de color blanco y la siguiente de gris claro alternadamente para facilitar la lectura.
* **`table-hover`**: Resalta con color gris la fila sobre la cual el usuario pasa el puntero del mouse.
* **`mb-0`**: Quita el margen sobrante debajo de la tabla.

---

### 6. Encabezados de la Tabla
```html
                    <thead class="table-dark">
                        <tr>
                            <th>N° Venta</th>
                            <th>Fecha</th>
                            <th>Cliente</th>
                            <th>Vendedor</th>
                            <th>Total</th>
                            <th style="width: 240px;">Acciones</th>
                        </tr>
                    </thead>
```
* **`table-dark`**: Pone la cabecera con fondo oscuro y letras blancas.
* Define las columnas de datos y le fija un ancho de 240 píxeles a la columna de acciones para que los tres botones entren holgados.

---

### 7. Cuerpo de la Tabla y Recorrido de Registros (`foreach`)
```html
                    <tbody>
                        <?php foreach ($ventas as $v): ?>
                            <tr>
```
* Inicia un ciclo que recorre una por una todas las ventas obtenidas de la base de datos. Por cada venta, crea una fila `<tr>`.

#### Columna 1: Número de Venta
```php
<td>#<?php echo $v["id_venta"]; ?></td>
```
* Muestra el ID de la venta anteponiendo un numeral (ejemplo: `#15`).

#### Columna 2: Fecha con Formato
```php
<td><?php echo date("d/m/Y H:i", strtotime($v["fecha"])); ?></td>
```
* La base de datos entrega la fecha en formato internacional `AAAA-MM-DD HH:MM:SS`.
* **`strtotime(...)`**: Convierte ese texto a una marca de tiempo.
* **`date("d/m/Y H:i", ...)`**: Lo reformatea a un estilo claro para el usuario: `Día/Mes/Año Hora:Minutos` (ejemplo: `20/11/2026 14:30`).

#### Columna 3 y 4: Cliente y Vendedor (Seguridad XSS)
```php
<td><?php echo htmlspecialchars($v["cli_nombre"] . " " . $v["cli_apellido"]); ?></td>
<td><?php echo htmlspecialchars($v["vendedor"]); ?></td>
```
* Concatena el nombre y apellido del cliente, y muestra el nombre del vendedor.
* **`htmlspecialchars(...)`**: Protege la aplicación contra ataques XSS. Convierte caracteres especiales en entidades de texto plano seguras para que nadie pueda ejecutar código malicioso a través de los nombres.

#### Columna 5: Importe Total Formateado en Moneda
```php
<td><strong>$<?php echo number_format($v["total"], 2, ",", "."); ?></strong></td>
```
* **`number_format($v["total"], 2, ",", ".")`**: Toma el número numérico y lo muestra con formato de moneda tradicional: 2 decimales, separando los decimales con una coma (`,`) y los miles con un punto (`.`). Ejemplo: `$15.450,00`.

#### Columna 6: Botones de Acción
```html
<td>
    <a href="ver_venta.php?id=<?php echo $v["id_venta"]; ?>" class="btn btn-info btn-sm text-white">Ver Detalle</a>
    <a href="editar_venta.php?id=<?php echo $v["id_venta"]; ?>" class="btn btn-warning btn-sm">Editar</a>
    <a href="ventas.php?eliminar=<?php echo $v["id_venta"]; ?>" class="btn btn-danger btn-sm"
       onclick="return confirm('¿Seguro que querés eliminar esta venta?');">Eliminar</a>
</td>
```
* **Ver Detalle (`btn-info btn-sm text-white`)**: Botón celeste que lleva a `ver_venta.php` pasando el ID de la venta para consultar los productos exactos que se compraron.
* **Editar (`btn-warning btn-sm`)**: Botón amarillo que abre `editar_venta.php` por si se necesita corregir algún dato.
* **Eliminar (`btn-danger btn-sm`)**: Botón rojo que recarga la misma página pasando el parámetro `?eliminar=ID`.
  * **`onclick="return confirm('...');"`**: Código en JavaScript que abre una ventana emergente en el navegador pidiendo confirmación. Si el usuario presiona "Cancelar", la acción se interrumpe y la venta no se borra, evitando clics accidentales.
