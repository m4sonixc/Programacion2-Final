# Explicación Detallada y Completa de `ventas.php`

Este archivo es el **módulo principal de gestión de ventas** del sistema del *Taller de Pachi*. Cumple tres funciones centrales:
1. **Seguridad:** Verifica que solo usuarios autenticados puedan ingresar.
2. **Eliminación inteligente de ventas:** Si se solicita borrar una venta, no solo la elimina, sino que devuelve automáticamente los productos al inventario (restaura el stock) usando transacciones seguras.
3. **Listado visual:** Muestra en una tabla moderna todas las ventas registradas con sus datos más importantes (fecha, cliente, vendedor, monto total y botones de acción).

---

## PARTE 1: El Código PHP (Lógica del Servidor)

El archivo comienza con un bloque de PHP que se ejecuta en el servidor antes de enviar cualquier elemento visual al navegador.

### 1. Inclusión de Archivos y Seguridad Inicial
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Llama al archivo de seguridad. Si el usuario no inició sesión, este archivo detiene todo y lo expulsa al `login.php`. El `require_once` asegura que se cargue una única vez y que, si el archivo falta, el sistema no continúe por seguridad.
* **`require_once "config/conexion.php";`**: Trae la conexión a la base de datos MySQL mediante el objeto `$conexion` (PDO).

---

### 2. Variables para Avisos al Usuario
```php
$mensaje = "";
$tipo_alerta = "";
```
* **`$mensaje`**: Variable vacía que guardará el texto que se le mostrará al usuario (por ejemplo: *"Venta eliminada correctamente"*).
* **`$tipo_alerta`**: Guardará la clase de estilo para el aviso (por ejemplo `"success"` para color verde o `"danger"` para color rojo).

### 3. Proceso Completo de Eliminación de Venta (Con Restauración de Stock)
Este bloque solo se activa si en la dirección web (URL) viene el parámetro `eliminar` (por ejemplo: `ventas.php?eliminar=5`).

```php
if (isset($_GET["eliminar"])) {
    $id_venta = intval($_GET["eliminar"]);
```
### Captura y Saneamiento de Parámetros por URL

* **`$_GET["eliminar"]`:** Variable superglobal de PHP que captura el valor del parámetro `eliminar` enviado directamente a través de la URL (por ejemplo, `archivo.php?eliminar=5`).
* **`intval(...)`:** Función nativa de PHP que fuerza la conversión del valor recibido a un **número entero (`int`)**. Se utiliza como medida básica de seguridad y limpieza de datos: si un usuario manipula la URL e ingresa texto o código malicioso en lugar de un ID numérico, la función lo convierte automáticamente en `0` o extrae solo la parte numérica inicial.

* **`if (isset($_GET["eliminar"]))`**: Pregunta si se hizo clic en el botón de eliminar de alguna venta.
* **`intval($_GET["eliminar"])`**: Toma el valor recibido por la URL y lo convierte estrictamente a un número entero. Esto evita que alguien intente pasar texto malicioso o inyecciones por la URL.

#### Inicio de la Transacción en la Base de Datos
```php
    $conexion->beginTransaction();
    try {
```
* **`$conexion->beginTransaction();`**: Abre una **transacción**. Una transacción es un mecanismo de seguridad donde se le dice a la base de datos: *"Voy a hacer varios cambios juntos. Si todos salen bien, guárdalos; pero si falla aunque sea uno solo, cancela todo y déjalo como estaba antes"*. Esto evita que se borre la venta pero no se recupere el stock.
* **`try { ... }`**: Bloque de prueba donde se intentan realizar las operaciones.

#### Paso A: Consultar qué productos se vendieron en esa venta
```php
        $stmt_det = $conexion->prepare("SELECT id_producto, cantidad FROM detalle_ventas WHERE id_venta = ?");
        $stmt_det->execute([$id_venta]);
        $items = $stmt_det->fetchAll();
```
### Consulta de Detalle de Ventas (`PDO`)

Este proceso completo se encarga de revertir el inventario cuando se cancela o elimina una venta. Primero consulta qué productos formaban parte de esa operación y luego devuelve sus cantidades al stock disponible.

#### Flujo de ejecución:

1. **Consulta del detalle de la venta (`$stmt_det`):** Prepara y ejecuta una sentencia `SELECT` sobre la tabla `detalle_ventas` filtrando por el `$id_venta` específico. El objetivo es obtener únicamente el identificador (`id_producto`) y la `cantidad` vendida de cada artículo.
2. **Almacenamiento de los registros (`fetchAll()`):** Extrae todos los resultados devueltos por `$stmt_det` y los guarda juntos en el arreglo `$items`, dejando la lista lista para ser recorrida.
3. **Preparación de la actualización (`$stmt_stock`):** Define fuera del ciclo una consulta `UPDATE` sobre la tabla `productos` utilizando marcadores de posición (`?`). Al prepararla una sola vez como molde, se protege contra inyecciones SQL y se optimiza el rendimiento de la base de datos.
4. **Restauración del inventario (`foreach`):** Recorre uno por uno los productos guardados en `$items` y ejecuta `$stmt_stock` en cada vuelta, sumando nuevamente la `cantidad` vendida al `stock` actual del `id_producto` correspondiente.

#### Paso B: Devolver el stock a cada producto
```php
        $stmt_stock = $conexion->prepare("UPDATE productos SET stock = stock + ? WHERE id_producto = ?");
        foreach ($items as $item) {
            $stmt_stock->execute([$item["cantidad"], $item["id_producto"]]);
        }
```
Este bloque suma unidades al inventario de varios productos a la vez (por ejemplo, al anular una venta o registrar ingreso de mercadería). Para lograrlo de forma rápida y segura, utiliza el objeto **`$stmt_stock`** (*Statement* o sentencia preparada), que funciona como un **molde reutilizable** de la consulta SQL.

#### Funcionamiento paso a paso:

1. **Preparación del molde (`$conexion->prepare(...)`):** Antes de iniciar el ciclo, se guarda la consulta `UPDATE` dentro de la variable `$stmt_stock` usando signos de interrogación (`?`) como marcadores. Al hacerlo una sola vez fuera del bucle, la base de datos analiza y optimiza la instrucción una única vez, ahorrando recursos del servidor.
2. **Recorrido de productos (`foreach ($items as $item)`):** Inicia un ciclo que lee uno por uno todos los productos contenidos en el arreglo `$items`.
3. **Ejecución segura en cada vuelta (`$stmt_stock->execute([...])`):** Dentro del ciclo, se reutiliza el objeto `$stmt_stock` para ejecutar la actualización pasando los datos reales en un arreglo. Esto reemplaza los signos `?` en orden estricto y protege contra inyecciones SQL:
   * **Primer parámetro (`$item["cantidad"]`):** Suma esa cantidad al valor actual de la columna `stock`.
   * **Segundo parámetro (`$item["id_producto"]`):** Indica exactamente qué registro de la tabla `productos` debe modificarse.

#### Paso C: Eliminar los detalles y la venta
```php
        $stmt_del_det = $conexion->prepare("DELETE FROM detalle_ventas WHERE id_venta = ?");
        $stmt_del_det->execute([$id_venta]);

        $stmt_del_venta = $conexion->prepare("DELETE FROM ventas WHERE id_venta = ?");
        $stmt_del_venta->execute([$id_venta]);
```
Este proceso se encarga de revertir una venta completa en la base de datos. Para mantener la integridad de los datos y respetar las claves foráneas (relaciones entre tablas), la operación se ejecuta en tres etapas secuenciales:

1. **Restauración del inventario (`$stmt_stock`):**
   * Prepara una única consulta `UPDATE` fuera del bucle para optimizar el rendimiento y evitar inyecciones SQL.
   * Recorre todos los productos asociados a la venta mediante un ciclo `foreach` y ejecuta la sentencia (`->execute()`), sumando nuevamente al `stock` de la tabla `productos` la cantidad que había sido descontada.

2. **Eliminación del detalle de venta (`$stmt_del_det`):**
   * Prepara y ejecuta una sentencia `DELETE` en la tabla hija `detalle_ventas` filtrando por el `id_venta`.
   * Este paso debe ejecutarse **antes** de borrar la venta principal para evitar errores de restricción de clave foránea (registros huérfanos).

3. **Eliminación de la venta principal (`$stmt_del_venta`):**
   * Una vez devuelto el stock y limpios los registros dependientes, prepara y ejecuta el `DELETE` final sobre la tabla padre `ventas`, eliminando por completo la cabecera de la operación mediante su `id_venta`.
#### Paso D: Confirmación del éxito
```php
        $conexion->commit();
        $mensaje = "Venta #$id_venta eliminada correctamente y stock restaurado.";
        $tipo_alerta = "success";
    }
```
1. **Confirmación de cambios (`$conexion->commit()`):** Guarda de manera permanente en la base de datos todas las consultas ejecutadas dentro de la transacción actual (tanto la eliminación de la venta como la restauración del stock). Si ocurre algún fallo previo, esta línea no se ejecuta y se revierte todo con `rollBack()`.
2. **Mensaje de confirmación (`$mensaje`):** Define el texto informativo que verá el usuario en pantalla, interpolando el identificador de la operación (`$id_venta`) para confirmar que la venta fue eliminada y el inventario actualizado.
3. **Estado visual de la alerta (`$tipo_alerta = "success"`):** Asigna la categoría de éxito para que la interfaz gráfica (por ejemplo, una alerta de Bootstrap) renderice la notificación con el estilo y color correspondientes (verde).

#### Paso E: Manejo de fallos (Rollback)
```php
    } catch (Exception $e) {
        $conexion->rollBack();
        $mensaje = "Error al eliminar la venta.";
        $tipo_alerta = "danger";
    }
}
```
* Si ocurre cualquier problema técnico durante el proceso, el bloque `catch` atrapa el error.
* **`$conexion->rollBack();`**: Deshace absolutamente todo lo que se haya hecho en ese intento. No se descuenta ni se borra nada, protegiendo la integridad de la base de datos.
* Se define el mensaje de error y el color rojo (`danger`).

### 4. Consulta para Listar Todas las Ventas
```php
$sql_ventas = "SELECT v.id_venta, v.fecha, v.total, 
                      c.nombre AS cli_nombre, c.apellido AS cli_apellido,
                      u.nombre AS vendedor
               FROM ventas v
               INNER JOIN clientes c ON v.id_cliente = c.id_cliente
               INNER JOIN usuarios u ON v.id_usuario = u.id_usuario
               ORDER BY v.id_venta DESC";
$ventas = $conexion->query($sql_ventas)->fetchAll();
```
Este bloque obtiene el listado completo de ventas registradas, cruzando información de distintas tablas para mostrar datos legibles (nombres de clientes y vendedores) en lugar de solo identificadores numéricos.

#### Funcionamiento paso a paso:

1. **Selección de datos principales (`SELECT`):** Define la consulta SQL (`$sql_ventas`) extrayendo el número de comprobante (`id_venta`), la `fecha` y el monto `total` desde la tabla `ventas` (abreviada con el alias `v`).
2. **Cruce de tablas y alias (`INNER JOIN` y `AS`):** Relaciona cada venta con sus registros correspondientes en otras dos tablas mediante sus claves foráneas:
   * **Clientes (`c`):** Cruza por `id_cliente` para obtener el nombre y apellido del comprador, renombrándolos como `cli_nombre` y `cli_apellido` para evitar conflictos con columnas del mismo nombre.
   * **Usuarios (`u`):** Cruza por `id_usuario` para obtener el nombre del empleado que realizó la operación, asignándole el alias `vendedor`.
3. **Ordenamiento descendente (`ORDER BY v.id_venta DESC`):** Organiza los resultados de mayor a menor según el ID de venta, asegurando que las operaciones más recientes aparezcan siempre al principio del listado.
4. **Ejecución directa y almacenamiento (`query()` y `fetchAll()`):** Ejecuta la sentencia directamente sobre la conexión (al ser una consulta fija sin parámetros externos ingresados por el usuario, no requiere preparación previa) y guarda todos los registros resultantes en el arreglo `$ventas` para mostrarlos en la interfaz.

## PARTE 2: El Código HTML y la Interfaz Visual

A partir del cierre de PHP, se genera el documento que ve el usuario en su pantalla.

### 1. Cabecera HTML y Recursos
```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
```

* **`viewport`**: Hace que la página sea responsiva y se adapte al tamaño de teléfonos, tablets o computadoras.
* **`link bootstrap`**: Carga los estilos visuales de Bootstrap 5 desde internet.

### 7. Cuerpo de la Tabla y Recorrido de Registros (`foreach`)
```html
                    <tbody>
                        <?php foreach ($ventas as $v): ?>
                            <tr>
```
* Inicia un ciclo que recorre una por una todas las ventas obtenidas de la base de datos. Por cada venta, crea una fila `<tr>`.

#### Columna 1: Número de Venta
```php
<td>#<?php echo $v["id_venta"]; ?></td>
```
Esta línea combina código **HTML** y **PHP** para imprimir dinámicamente el identificador de una venta dentro de una celda de tabla:

1. **Celda HTML (`<td>...</td>`):** Define una celda estándar dentro de una fila de tabla HTML (`<tr>`), encargándose de estructurar visualmente el dato en pantalla.
2. **Prefijo visual (`#`):** Carácter de texto estático en HTML que se antepone al número para darle formato de identificador o comprobante (por ejemplo: `#15`).
3. **Etiqueta de apertura y cierre (`<?php ... ?>`):** Delimita el bloque donde el servidor deja de interpretar HTML puro y ejecuta código PHP antes de enviar la página al navegador.
4. **Impresión en pantalla (`echo`):** Instrucción de PHP que escribe directamente en el documento HTML el valor resultante.
5. **Acceso al registro (`$v["id_venta"]`):** Accede al array asociativo `$v` (que representa una fila o registro individual de venta obtenido de la base de datos) y extrae específicamente el valor correspondiente a la columna `id_venta`.

#### Columna 2: Fecha con Formato
```php
<td><?php echo date("d/m/Y H:i", strtotime($v["fecha"])); ?></td>
```
* La base de datos entrega la fecha en formato internacional `AAAA-MM-DD HH:MM:SS`.
* **`strtotime(...)`**: Convierte ese texto a una marca de tiempo.
* **`date("d/m/Y H:i", ...)`**: Lo reformatea a un estilo claro para el usuario: `Día/Mes/Año Hora:Minutos` (ejemplo: `20/11/2026 14:30`).

#### Columna 3 y 4: Cliente y Vendedor (Seguridad XSS)
```php
<td><?php echo htmlspecialchars($v["cli_nombre"] . " " . $v["cli_apellido"]); ?></td>
<td><?php echo htmlspecialchars($v["vendedor"]); ?></td>
```
* Concatena el nombre y apellido del cliente, y muestra el nombre del vendedor.
* **`htmlspecialchars(...)`**: Protege la aplicación contra ataques XSS. Convierte caracteres especiales en entidades de texto plano seguras para que nadie pueda ejecutar código malicioso a través de los nombres.

#### Columna 5: Importe Total Formateado en Moneda
```php
<td><strong>$<?php echo number_format($v["total"], 2, ",", "."); ?></strong></td>
```
* **`number_format($v["total"], 2, ",", ".")`**: Toma el número numérico y lo muestra con formato de moneda tradicional: 2 decimales, separando los decimales con una coma (`,`) y los miles con un punto (`.`). Ejemplo: `$15.450,00`.

#### Columna 6: Botones de Acción
```html
<td>
    <a href="ver_venta.php?id=<?php echo $v["id_venta"]; ?>" class="btn btn-info btn-sm text-white">Ver Detalle</a>
    <a href="editar_venta.php?id=<?php echo $v["id_venta"]; ?>" class="btn btn-warning btn-sm">Editar</a>
    <a href="ventas.php?eliminar=<?php echo $v["id_venta"]; ?>" class="btn btn-danger btn-sm"
       onclick="return confirm('¿Seguro que querés eliminar esta venta?');">Eliminar</a>
</td>
```
* **`<td>` (Table Data):** Etiqueta HTML que define una celda estándar dentro de una fila de una tabla, utilizada aquí para agrupar los botones de acción de cada registro.
* **`href="..."` con parámetros `GET`:** Atributo de enlace que envía el identificador único de la venta (`id` o `eliminar`) a través de la URL hacia el archivo PHP destino.
* **`<?php echo $v["id_venta"]; ?>`:** Etiqueta de salida de PHP que imprime dinámicamente el ID de la venta correspondiente a la fila actual dentro del enlace.
* **`btn btn-... btn-sm` (Bootstrap 5):** Clases CSS de Bootstrap que dan estilo de botón compacto (`btn-sm`) con colores semánticos: celeste informativo (`btn-info`), amarillo de advertencia (`btn-warning`) y rojo de peligro (`btn-danger`).
* **`onclick="return confirm(...);"`:** Evento de JavaScript que muestra una ventana emergente de confirmación antes de ejecutar el enlace. Si el usuario presiona "Cancelar", devuelve `false` y bloquea la redirección.

1. **Ver Detalle (`ver_venta.php?id=...`):** Redirige a la vista de detalle enviando el ID de la venta por método `GET` para consultar los productos y montos asociados sin modificarlos.
2. **Editar (`editar_venta.php?id=...`):** Redirige al formulario de edición pasando el ID de la venta para cargar y actualizar sus datos existentes.
3. **Eliminar (`ventas.php?eliminar=...`):** Ejecuta una validación preventiva en JavaScript (`confirm(...)`) antes de recargar `ventas.php` con el parámetro `eliminar` y el ID del registro, evitando borrados accidentales.
