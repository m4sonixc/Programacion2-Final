# Explicación Detallada y Completa de `ver_venta.php`

Este archivo es el **módulo de visualización o comprobante de venta** del sistema del *Taller de Pachi*. 

Su función principal es actuar como un **recibo o factura digital detallada**, mostrando toda la información de una venta específica: los datos del cliente, la fecha, quién atendió la venta, el desglose de cada producto comprado con sus precios y el importe total final.

---

## SECCIÓN 1: Código PHP (Lógica del Servidor y Consultas)

El archivo arranca en el servidor procesando los identificadores y realizando las consultas a la base de datos antes de pintar el diseño en pantalla.

### 1. Inclusión de Seguridad y Conexión
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Revisa si el usuario inició sesión. Si no está conectado, detiene la carga y lo redirige a la pantalla de login.
* **`require_once "config/conexion.php";`**: Trae la conexión activa a la base de datos MySQL (objeto `$conexion` vía PDO).

---

### 2. Captura y Limpieza del ID de la Venta
```php
$id_venta = intval($_GET["id"] ?? 0);
```
* **`$_GET["id"]`**: Lee el número de venta que viene en la dirección web (por ejemplo, en `ver_venta.php?id=8`, toma el número `8`).
* **`?? 0`**: Si por algún motivo se entra a la página sin poner un ID en la URL, asigna el valor cero por defecto para evitar errores de variable no definida.
* **`intval(...)`**: Convierte el dato recibido estrictamente a un número entero. Es una medida de seguridad fundamental que evita ataques e inyecciones de código a través de la URL.

---

### 3. Consulta de la Cabecera de la Venta (Datos Generales)
```php
$sql_cab = "SELECT v.*, c.nombre AS cli_nombre, c.apellido AS cli_apellido, c.telefono,
                   u.nombre AS vendedor
            FROM ventas v
            INNER JOIN clientes c ON v.id_cliente = c.id_cliente
            INNER JOIN usuarios u ON v.id_usuario = u.id_usuario
            WHERE v.id_venta = ?";
$stmt_cab = $conexion->prepare($sql_cab);
$stmt_cab->execute([$id_venta]);
$venta = $stmt_cab->fetch();
```
* **`v.*`**: Selecciona todos los campos de la tabla `ventas` (como `id_venta`, `fecha` y `total`).
* **`c.nombre AS cli_nombre, c.apellido AS cli_apellido, c.telefono`**: Extrae el nombre, apellido y teléfono del cliente desde la tabla `clientes`.
* **`u.nombre AS vendedor`**: Extrae el nombre del usuario o empleado que registró la operación desde la tabla `usuarios`.
* **`INNER JOIN`**: Relaciona las tres tablas mediante sus claves (`id_cliente` e `id_usuario`).
* **`WHERE v.id_venta = ?`**: Filtra para buscar únicamente la venta solicitada.
* **`prepare(...)` y `execute([$id_venta])`**: Utiliza sentencias preparadas de PDO para garantizar inmunidad contra inyecciones SQL.
* **`$stmt_cab->fetch()`**: Obtiene la única fila que coincide con ese ID de venta y la guarda en la variable `$venta`.

---

### 4. Control de Existencia de la Venta
```php
if (!$venta) {
    header("Location: ventas.php");
    exit();
}
```
* **`if (!$venta)`**: Evalúa si la consulta no devolvió resultados (por ejemplo, si el usuario escribió un ID inexistente en la URL como `ver_venta.php?id=99999` o si puso un cero).
* **`header("Location: ventas.php")` y `exit()`**: Si la venta no existe en la base de datos, expulsa al usuario devolviéndolo al listado general de ventas (`ventas.php`) y frena la ejecución en el acto.

---

### 5. Consulta del Detalle de la Venta (Lista de Productos)
```php
$sql_det = "SELECT d.*, p.nombre AS producto_nombre
            FROM detalle_ventas d
            INNER JOIN productos p ON d.id_producto = p.id_producto
            WHERE d.id_venta = ?";
$stmt_det = $conexion->prepare($sql_det);
$stmt_det->execute([$id_venta]);
$detalles = $stmt_det->fetchAll();
```
* **`d.*`**: Selecciona los datos guardados en `detalle_ventas` (cantidad, precio unitario histórico y subtotal de cada ítem).
* **`p.nombre AS producto_nombre`**: Obtiene el nombre del artículo desde la tabla `productos`.
* **`INNER JOIN productos p ON d.id_producto = p.id_producto`**: Cruza los artículos para saber qué producto corresponde a cada renglón.
* **`WHERE d.id_venta = ?`**: Trae únicamente los renglones que pertenecen a esta venta.
* **`fetchAll()`**: Como una venta puede tener varios productos, guarda todos los renglones devueltos en forma de lista (arreglo) en la variable `$detalles`.

## SECCIÓN 2: Código HTML y Bootstrap (Presentación Visual)

Una vez que PHP recolectó los datos de la base de datos, se genera la interfaz visual que el usuario ve en el navegador.

### 1. Encabezado y Título Dinámico
```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Detalle de Venta #<?php echo $id_venta; ?> - Taller de Pachi</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
```
* Declara la estructura HTML5 con codificación UTF-8 y diseño adaptable (*viewport*).
* **`<title>` con PHP embebido**: Muestra dinámicamente en la pestaña del navegador el número de venta correspondiente (por ejemplo: *"Detalle de Venta #8 - Taller de Pachi"*).
* Carga los estilos de Bootstrap 5 desde su CDN.

---

### 2. Estructura del Cuerpo y Barra de Navegación
```html
<body class="bg-light">
    <?php include "navbar.php"; ?>
    <div class="container">
```
* **`class="bg-light"`**: Pinta el fondo de gris claro.
* **`<?php include "navbar.php"; ?>`**: Inserta la barra de menú superior compartida por todo el sistema.
* **`container`**: Centra el contenido en pantalla con márgenes laterales simétricos.

---

### 3. Encabezado de la Vista y Botones de Acción
```html
        <div class="d-flex justify-content-between align-items-center mb-4">
            <h3>Detalle de Venta #<?php echo $venta["id_venta"]; ?></h3>
            <div>
                <a href="editar_venta.php?id=<?php echo $id_venta; ?>" class="btn btn-warning">Editar</a>
                <a href="ventas.php" class="btn btn-secondary">Volver</a>
            </div>
        </div>
```
* **`d-flex justify-content-between align-items-center`**: Alinea el título de la venta a la izquierda y los botones a la derecha en una misma línea.
* **Botón Editar (`btn-warning`)**: Botón amarillo que permite ir a la pantalla de edición (`editar_venta.php`) llevando el ID de esta venta.
* **Botón Volver (`btn-secondary`)**: Botón gris que regresa directamente al listado general de ventas (`ventas.php`).

---

### 4. Tarjeta 1: Información General (Cabecera del Comprobante)
```html
        <div class="card shadow-sm mb-4">
            <div class="card-header bg-dark text-white">Datos de la Venta</div>
            <div class="card-body row">
```
* Muestra una tarjeta blanca con sombra ligera (`card shadow-sm`) y una barra de título negra con letras blancas (`bg-dark text-white`).
* El cuerpo de la tarjeta (`card-body row`) utiliza el sistema de columnas de Bootstrap dividido en 3 bloques (`col-md-4` cada uno):

#### Bloque 1: Cliente
```php
                <div class="col-md-4">
                    <strong>Cliente:</strong><br>
                    <?php echo htmlspecialchars($venta["cli_nombre"] . " " . $venta["cli_apellido"]); ?><br>
                    <small class="text-muted">Tel: <?php echo htmlspecialchars($venta["telefono"]); ?></small>
                </div>
```
* Muestra el nombre y apellido del cliente en negrita y su teléfono en letra secundaria gris (`text-muted`).
* **`htmlspecialchars(...)`**: Protege la aplicación contra ataques de inyección de código XSS en caso de que algún nombre o número tenga caracteres especiales.

#### Bloque 2: Fecha de la Venta
```php
                <div class="col-md-4">
                    <strong>Fecha:</strong><br>
                    <?php echo date("d/m/Y H:i", strtotime($venta["fecha"])); ?>
                </div>
```
* Toma la fecha original del servidor (`AAAA-MM-DD HH:MM:SS`), la transforma en una marca de tiempo con `strtotime` y la formatea en orden legible con `date("d/m/Y H:i")` (por ejemplo: `20/11/2026 14:35`).

#### Bloque 3: Vendedor
```php
                <div class="col-md-4">
                    <strong>Atendido por:</strong><br>
                    <?php echo htmlspecialchars($venta["vendedor"]); ?>
                </div>
```
* Muestra el nombre del empleado que realizó la transacción, protegido con `htmlspecialchars`.

---

### 5. Tarjeta 2: Tabla de Productos Vendidos (Detalle)
```html
        <div class="card shadow-sm">
            <div class="card-header">Productos Vendidos</div>
            <div class="card-body p-0">
                <table class="table table-bordered mb-0">
```
* Segunda tarjeta contenedora.
* **`p-0` y `mb-0`**: Quitan márgenes y rellenos para que la tabla ocupe todo el ancho interior de la tarjeta de forma limpia.
* **`table-bordered`**: Añade bordes visibles a todas las celdas de la tabla para que parezca una factura tradicional.

#### Cabecera de la Tabla
```html
                    <thead class="table-light">
                        <tr>
                            <th>Producto</th>
                            <th>Cantidad</th>
                            <th>Precio Unitario</th>
                            <th>Subtotal</th>
                        </tr>
                    </thead>
```
* Define las columnas con fondo gris claro (`table-light`): el nombre del producto, las unidades vendidas, el precio de cada unidad y el subtotal calculado.

#### Cuerpo de la Tabla (Filas de Productos con `foreach`)
```php
                    <tbody>
                        <?php foreach ($detalles as $d): ?>
                            <tr>
                                <td><?php echo htmlspecialchars($d["producto_nombre"]); ?></td>
                                <td><?php echo $d["cantidad"]; ?></td>
                                <td>$<?php echo number_format($d["precio_unitario"], 2, ",", "."); ?></td>
                                <td>$<?php echo number_format($d["subtotal"], 2, ",", "."); ?></td>
                            </tr>
                        <?php endforeach; ?>
                    </tbody>
```
* **`foreach ($detalles as $d)`**: Ciclo repetitivo de PHP que recorre todos los artículos comprados y genera una fila `<tr>` por cada uno de ellos.
* **`htmlspecialchars($d["producto_nombre"])`**: Imprime el nombre del repuesto o producto de manera segura.
* **`$d["cantidad"]`**: Muestra el número de unidades vendidas.
* **`number_format(..., 2, ",", ".")`**: Formatea tanto el precio unitario como el subtotal con 2 decimales, coma para los centavos y punto para los miles (ejemplo: `$2.500,00`).

#### Pie de la Tabla (Total Final)
```php
                    <tfoot>
                        <tr class="table-secondary">
                            <th colspan="3" class="text-end">TOTAL DE LA VENTA:</th>
                            <th>$<?php echo number_format($venta["total"], 2, ",", "."); ?></th>
                        </tr>
                    </tfoot>
```
* **`<tfoot>`**: Etiqueta semántica de HTML para definir el pie de una tabla.
* **`table-secondary`**: Aplica un sombreado gris diferenciador a toda la fila del total.
* **`colspan="3"`**: Hace que la celda del texto "TOTAL DE LA VENTA:" ocupe el ancho de las tres primeras columnas combinadas.
* **`text-end`**: Alinea el rótulo hacia la derecha para que quede pegado al número del total.
* **`number_format($venta["total"], 2, ",", ".")`**: Imprime el importe total general de la venta traído de la cabecera con el formato monetario correspondiente.
