# Explicación Exhaustiva y Completa de `usuarios.php`

Este archivo es el **módulo de administración de usuarios y seguridad** del sistema del *Taller de Pachi*. 

Permite gestionar a los empleados o administradores que tienen acceso al sistema implementando un **CRUD completo** (Crear, Leer, Actualizar y Eliminar) en una **única pantalla**:
1. **Listar:** Muestra todos los usuarios registrados con su identificador, nombre y nombre de inicio de sesión.
2. **Crear:** Permite registrar nuevos usuarios encriptando su contraseña con algoritmos de alta seguridad (`bcrypt`).
3. **Editar:** Permite cambiar el nombre o el usuario, y ofrece la opción de actualizar la contraseña o mantener la actual si el campo se deja vacío.
4. **Eliminar y Auto-protección:** Borra cuentas de usuario, pero incluye dos capas de seguridad vitales:
   - **Impide el auto-borrado:** Un usuario no puede eliminarse a sí mismo mientras está conectado.
   - **Protección de historial comercial:** Impide borrar usuarios que ya hayan registrado ventas en el taller.
5. **Control de duplicados:** Evita que existan dos usuarios con el mismo nombre de inicio de sesión.

## BLOQUE 1: Código PHP (Lógica del Servidor, Seguridad y Base de Datos)

Todo el código contenido entre `<?php` y `?>` se ejecuta en el servidor antes de procesar el código HTML.

### 1. Inclusión de Archivos y Control de Sesión
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Filtro de autenticación. Si la persona no ha iniciado sesión, detiene la ejecución inmediatamente y la expulsa al `login.php`. La directiva `require_once` garantiza que el archivo se incluya una sola vez y frena el sistema si no se encuentra.
* **`require_once "config/conexion.php";`**: Abre la conexión a la base de datos MySQL mediante la variable `$conexion` (usando PDO).

---

### 2. Inicialización de Variables de Estado
```php
$mensaje = "";
$tipo_alerta = "";
$id_editar = "";
$nombre_editar = "";
$usuario_editar = "";
```
* **`$mensaje = "";`**: Cadena de texto vacía que almacenará el mensaje informativo o de alerta que se le mostrará al usuario.
* **`$tipo_alerta = "";`**: Guardará la clase de estilo visual de Bootstrap (`"success"` para verde, `"danger"` para rojo o `"warning"` para amarillo).
* **`$id_editar = "";`**: Almacena el ID del usuario que se va a modificar. Si está vacío, el formulario se usará para crear un usuario nuevo; si contiene un número, se usará para editarlo.
* **`$nombre_editar = "";`**: Guarda el nombre real del usuario para precargarlo en el formulario durante una edición.
* **`$usuario_editar = "";`**: Guarda el nombre de usuario (login) para precargarlo en el formulario durante una edición.

### 3. Operación de Eliminación con Reglas de Seguridad (`GET["eliminar"]`)
Se ejecuta cuando en la URL viene el parámetro `eliminar` (por ejemplo: `usuarios.php?eliminar=3`).

```php
if (isset($_GET["eliminar"])) {
    $id = intval($_GET["eliminar"]);
```
* **`if (isset($_GET["eliminar"]))`**: Evalúa si se presionó el botón de eliminar.
* **`intval(...)`**: Convierte el valor de la URL estrictamente a un número entero para evitar inyecciones SQL.

#### Regla de Seguridad 1: Prevención del Auto-borrado
```php
    if ($id == $_SESSION["id_usuario"]) {
        $mensaje = "No podés eliminar tu propio usuario mientras estás conectado.";
        $tipo_alerta = "warning";
    } else {
```
* Compara el ID que se quiere eliminar (`$id`) con el ID del usuario que tiene la sesión abierta actualmente (`$_SESSION["id_usuario"]`).
* Si coinciden, bloquea la acción y muestra un aviso amarillo (`warning`): *"No podés eliminar tu propio usuario mientras estás conectado."* Esto evita que un administrador borre accidentalmente su propia cuenta y quede atrapado sin acceso.

#### Regla de Seguridad 2: Borrado Protegido por Integridad Referencial
```php
        try {
            $stmt = $conexion->prepare("DELETE FROM usuarios WHERE id_usuario = ?");
            $stmt->execute([$id]);
            $mensaje = "Usuario eliminado correctamente.";
            $tipo_alerta = "success";
        } catch (PDOException $e) {
            $mensaje = "No se puede eliminar el usuario porque tiene ventas registradas.";
            $tipo_alerta = "danger";
        }
    }
}
```
* **`try / catch`:** Estructura de control de errores. El bloque `try` intenta ejecutar una operación crítica en la base de datos; si ocurre un fallo, el flujo salta al bloque `catch` para manejarlo de forma controlada sin detener ni romper la aplicación.
* **`prepare()` y marcador `?`:** Prepara la sentencia SQL `DELETE` utilizando un parámetro posicional (`?`) en lugar de concatenar variables directamente, protegiendo la consulta contra ataques de inyección SQL.
* **`execute([$id])`:** Ejecuta la consulta preparada reemplazando de forma segura el marcador `?` con el valor del identificador `$id`.
* **`PDOException $e`:** Clase de excepción nativa de PDO que captura errores específicos de la base de datos (como restricciones de clave foránea o fallos de conexión).
* **`$mensaje` y `$tipo_alerta`:** Variables de estado utilizadas para enviar notificaciones visuales a la interfaz de usuario (por ejemplo, alertas de éxito `"success"` o de error `"danger"`).

1. **Preparación y borrado:** El sistema prepara la eliminación del registro en la tabla `usuarios` filtrando por `id_usuario` y ejecuta la orden pasando el `$id` correspondiente.
2. **Confirmación exitosa:** Si la base de datos permite la operación, se asigna el mensaje `"Usuario eliminado correctamente."` junto con el estado `"success"`.
3. **Control de integridad referencial:** Si el usuario tiene registros asociados en otras tablas (como ventas vinculadas mediante una clave foránea), la base de datos bloquea el borrado y lanza una `PDOException`. El bloque `catch` intercepta ese error y muestra un mensaje descriptivo (`"No se puede eliminar el usuario porque tiene ventas registradas."`) con el estado `"danger"`.

### 4. Carga de Datos para Edición (`GET["editar"]`)
Se ejecuta cuando se hace clic en el botón amarillo "Editar" de alguna fila (por ejemplo: `usuarios.php?editar=2`).

```php
if (isset($_GET["editar"])) {
    $id_editar = intval($_GET["editar"]);
    $stmt = $conexion->prepare("SELECT id_usuario, nombre, usuario FROM usuarios WHERE id_usuario = ?");
    $stmt->execute([$id_editar]);
    if ($fila = $stmt->fetch()) {
        $nombre_editar = $fila["nombre"];
        $usuario_editar = $fila["usuario"];
    }
}
```
Este bloque recupera los datos actuales de un usuario desde la base de datos para precargarlos en un formulario de edición:

1. **Detección del parámetro en la URL (`isset($_GET["editar"])`):** Verifica si se recibió el parámetro `editar` a través de la URL (por ejemplo, `usuarios.php?editar=5`).
2. **Sanitización del ID (`intval(...)`):** Convierte el valor recibido en un número entero estricto y lo guarda en `$id_editar`, asegurando que el dato sea numérico antes de consultarlo.
3. **Consulta preparada (`$conexion->prepare(...)`):** Prepara la sentencia `SELECT` utilizando un marcador de posición (`?`) para buscar únicamente el ID, nombre y usuario correspondientes, protegiendo la consulta contra inyecciones SQL.
4. **Ejecución (`$stmt->execute([$id_editar])`):** Ejecuta la consulta enviando el ID sanitizado como parámetro.
5. **Extracción y asignación (`if ($fila = $stmt->fetch())`):** Obtiene el registro encontrado. Si el usuario existe, extrae los valores de las columnas `nombre` y `usuario` y los guarda en `$nombre_editar` y `$usuario_editar` para mostrarlos en los campos del formulario.

### 5. Procesamiento del Formulario: Crear o Actualizar (`POST`)
Se ejecuta cuando el usuario presiona el botón principal del formulario para enviar datos.

```php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $id_usuario = $_POST["id_usuario"] ?? "";
    $nombre = trim($_POST["nombre"] ?? "");
    $usuario = trim($_POST["usuario"] ?? "");
    $password = $_POST["password"] ?? "";
```
* **`$_SERVER["REQUEST_METHOD"] == "POST"`**: Comprueba que la petición sea de tipo POST.
* **`$id_usuario`**: Rescata el ID del campo oculto. Si está vacío, se creará un usuario; si tiene un ID, se modificará.
* **`trim(...)`**: Remueve espacios en blanco accidentales de los extremos en el nombre y usuario.
* **`$password`**: Captura la contraseña escrita (a la contraseña no se le aplica `trim` por si intencionalmente contiene espacios).

#### Validación Condicional de Campos
```php
    if ($nombre == "" || $usuario == "" || ($id_usuario == "" && $password == "")) {
        $mensaje = "Completá todos los campos obligatorios.";
        $tipo_alerta = "danger";
    } else {
```
Este bloque verifica que los datos obligatorios estén completos antes de guardar o actualizar un usuario en la base de datos:

1. **Campos siempre obligatorios (`$nombre == "" || $usuario == ""`):** Comprueba si el nombre o el nombre de usuario están vacíos. Ambos datos son indispensables tanto al crear un usuario nuevo como al editar uno existente.
2. **Contraseña obligatoria solo al crear (`$id_usuario == "" && $password == ""`):** Evalúa dos condiciones en simultáneo: si `$id_usuario` está vacío (lo que indica que es un **registro nuevo**) y la contraseña también está vacía. Si se está **editando** un usuario existente (`$id_usuario` ya tiene un valor), permite dejar la contraseña en blanco para conservar la actual.
3. **Gestión de alertas (`$mensaje` y `$tipo_alerta`):** Si falla alguna de las validaciones anteriores, detiene el proceso, guarda el aviso `"Completá todos los campos obligatorios."` y define el estilo visual `"danger"` (alerta roja en Bootstrap) para mostrarlo en pantalla.
4. **Flujo alternativo (`else`):** Si todos los campos obligatorios son válidos, el sistema continúa hacia el bloque encargado de insertar el nuevo registro o actualizar los datos en la base de datos.

#### Encriptación y Guardado en Base de Datos
```php
        try {
            if ($id_usuario == "") {
                $password_hash = password_hash($password, PASSWORD_DEFAULT);
                $stmt = $conexion->prepare("INSERT INTO usuarios (nombre, usuario, password) VALUES (?, ?, ?)");
                $stmt->execute([$nombre, $usuario, $password_hash]);
                $mensaje = "Usuario agregado correctamente.";
            } else {
```
El bloque utiliza manejo de excepciones (`try`) para ejecutar de forma segura el alta de un nuevo registro en la base de datos:

1. **Detección de nuevo registro (`if ($id_usuario == "")`):** Evalúa si la variable `$id_usuario` está vacía. Esto indica que el formulario se envió para crear un usuario nuevo en lugar de modificar uno existente (lo cual se maneja en la rama `else`).
2. **Encriptación de contraseña (`password_hash(...)`):** Transforma la contraseña en texto plano (`$password`) en un hash seguro e irreversible utilizando el algoritmo estándar recomendado por PHP (`PASSWORD_DEFAULT`) antes de guardarla.
3. **Preparación de consulta (`$conexion->prepare(...)`):** Prepara la sentencia SQL `INSERT` usando marcadores de posición (`?`) para separar la estructura de la consulta de los datos ingresados, bloqueando intentos de inyección SQL.
4. **Ejecución y confirmación (`$stmt->execute(...)`):** Envía los valores (`$nombre`, `$usuario` y `$password_hash`) en orden para completar los signos de interrogación, inserta el registro en la tabla `usuarios` y guarda el mensaje de éxito en `$mensaje`.
```php
                if ($password != "") {
                    $password_hash = password_hash($password, PASSWORD_DEFAULT);
                    $stmt = $conexion->prepare("UPDATE usuarios SET nombre = ?, usuario = ?, password = ? WHERE id_usuario = ?");
                    $stmt->execute([$nombre, $usuario, $password_hash, $id_usuario]);
                } else {
                    $stmt = $conexion->prepare("UPDATE usuarios SET nombre = ?, usuario = ? WHERE id_usuario = ?");
                    $stmt->execute([$nombre, $usuario, $id_usuario]);
                }
                $mensaje = "Usuario actualizado correctamente.";
            }
            $tipo_alerta = "success";
        } catch (PDOException $e) {
            $mensaje = "Error: ese nombre de usuario ya existe.";
            $tipo_alerta = "danger";
        }
    }
}
```
Este bloque gestiona la edición de los datos de un usuario existente en la base de datos, permitiendo actualizar su contraseña de forma opcional y controlando errores de duplicidad:

1. **Actualización con cambio de contraseña (`if ($password != "")`):** Si el campo de contraseña no está vacío, encripta la nueva clave mediante `password_hash()` usando el algoritmo seguro por defecto (`PASSWORD_DEFAULT`). Luego prepara y ejecuta una consulta `UPDATE` que modifica el nombre, el usuario y la contraseña filtrando por `id_usuario`.
2. **Actualización sin cambio de contraseña (`else`):** Si el campo de contraseña se dejó en blanco, ejecuta una consulta `UPDATE` que actualiza únicamente el nombre y el usuario, manteniendo intacta la contraseña actual en la base de datos.
3. **Consultas preparadas (`prepare` y `execute`):** Utiliza marcadores de posición (`?`) para enviar los parámetros de forma segura, evitando inyecciones SQL.
4. **Confirmación y manejo de excepciones (`try / catch`):** Si la operación tiene éxito, define un mensaje de confirmación y asigna el estilo visual `"success"` a `$tipo_alerta`. Si ocurre una excepción `PDOException` (por ejemplo, al intentar usar un nombre de usuario que ya está registrado como único), captura el error y muestra una alerta de tipo `"danger"`.

### 6. Consulta para Listar los Usuarios
```php
$usuarios = $conexion->query("SELECT id_usuario, nombre, usuario FROM usuarios ORDER BY id_usuario DESC")->fetchAll();
```
* Realiza una consulta directa a la tabla `usuarios`.
* Solo selecciona `id_usuario`, `nombre` y `usuario` (nunca el hash de la contraseña).
* **`ORDER BY id_usuario DESC`**: Ordena de mayor a menor para que el usuario más nuevo aparezca primero.
* **`fetchAll()`**: Guarda todas las filas en el arreglo `$usuarios`.

### Conceptos Clave

* **Operador Ternario (`? :`):** Forma abreviada de una estructura condicional `if-else` en una sola línea, utilizada para imprimir texto dinámico dentro de etiquetas HTML.
* **Sintaxis Alternativa (`if ... endif`):** Estructura de control de PHP diseñada para integrarse de forma limpia dentro de bloques HTML sin necesidad de usar llaves (`{}`).
* **Clases de Bootstrap (`btn`, `w-100`, `mt-2`):** Clases de estilo que dan formato de botón, ajustan el ancho al 100% del contenedor y añaden margen superior.

El cierre del formulario adapta sus botones según el estado de la variable `$id_editar`:

1. **Botón Principal Dinámico (`type="submit"`):** Evalúa si la variable `$id_editar` contiene un valor distinto de vacío (`!= ""`). Si existe un ID (modo edición), el botón muestra el texto **"Guardar Cambios"**; de lo contrario (modo creación), muestra **"Agregar Usuario"**.
2. **Botón Condicional de Cancelación:** Mediante el bloque `if ($id_editar != "")`, verifica si el formulario está en modo edición. Solo en ese caso renderiza el enlace **"Cancelar"**, el cual redirige nuevamente a `usuarios.php` para limpiar los parámetros y restablecer el formulario al estado inicial de registro.
3. **Cierre de Estructura:** Finaliza la etiqueta del formulario (`</form>`) y los contenedores de diseño de la tarjeta y la cuadrícula de Bootstrap (`</div>`).
