# Explicación Exhaustiva y Completa de `usuarios.php`

Este archivo es el **módulo de administración de usuarios y seguridad** del sistema del *Taller de Pachi*. 

Permite gestionar a los empleados o administradores que tienen acceso al sistema implementando un **CRUD completo** (Crear, Leer, Actualizar y Eliminar) en una **única pantalla**:
1. **Listar:** Muestra todos los usuarios registrados con su identificador, nombre y nombre de inicio de sesión.
2. **Crear:** Permite registrar nuevos usuarios encriptando su contraseña con algoritmos de alta seguridad (`bcrypt`).
3. **Editar:** Permite cambiar el nombre o el usuario, y ofrece la opción de actualizar la contraseña o mantener la actual si el campo se deja vacío.
4. **Eliminar y Auto-protección:** Borra cuentas de usuario, pero incluye dos capas de seguridad vitales:
   - **Impide el auto-borrado:** Un usuario no puede eliminarse a sí mismo mientras está conectado.
   - **Protección de historial comercial:** Impide borrar usuarios que ya hayan registrado ventas en el taller.
5. **Control de duplicados:** Evita que existan dos usuarios con el mismo nombre de inicio de sesión.

---

## BLOQUE 1: Código PHP (Lógica del Servidor, Seguridad y Base de Datos)

Todo el código contenido entre `<?php` y `?>` se ejecuta en el servidor antes de procesar el código HTML.

### 1. Inclusión de Archivos y Control de Sesión
```php
require_once "verificarsesion.php";
require_once "config/conexion.php";
```
* **`require_once "verificarsesion.php";`**: Filtro de autenticación. Si la persona no ha iniciado sesión, detiene la ejecución inmediatamente y la expulsa al `login.php`. La directiva `require_once` garantiza que el archivo se incluya una sola vez y frena el sistema si no se encuentra.
* **`require_once "config/conexion.php";`**: Abre la conexión a la base de datos MySQL mediante la variable `$conexion` (usando PDO).

---

### 2. Inicialización de Variables de Estado
```php
$mensaje = "";
$tipo_alerta = "";
$id_editar = "";
$nombre_editar = "";
$usuario_editar = "";
```
* **`$mensaje = "";`**: Cadena de texto vacía que almacenará el mensaje informativo o de alerta que se le mostrará al usuario.
* **`$tipo_alerta = "";`**: Guardará la clase de estilo visual de Bootstrap (`"success"` para verde, `"danger"` para rojo o `"warning"` para amarillo).
* **`$id_editar = "";`**: Almacena el ID del usuario que se va a modificar. Si está vacío, el formulario se usará para crear un usuario nuevo; si contiene un número, se usará para editarlo.
* **`$nombre_editar = "";`**: Guarda el nombre real del usuario para precargarlo en el formulario durante una edición.
* **`$usuario_editar = "";`**: Guarda el nombre de usuario (login) para precargarlo en el formulario durante una edición.

### 3. Operación de Eliminación con Reglas de Seguridad (`GET["eliminar"]`)
Se ejecuta cuando en la URL viene el parámetro `eliminar` (por ejemplo: `usuarios.php?eliminar=3`).

```php
if (isset($_GET["eliminar"])) {
    $id = intval($_GET["eliminar"]);
```
* **`if (isset($_GET["eliminar"]))`**: Evalúa si se presionó el botón de eliminar.
* **`intval(...)`**: Convierte el valor de la URL estrictamente a un número entero para evitar inyecciones SQL.

#### Regla de Seguridad 1: Prevención del Auto-borrado
```php
    if ($id == $_SESSION["id_usuario"]) {
        $mensaje = "No podés eliminar tu propio usuario mientras estás conectado.";
        $tipo_alerta = "warning";
    } else {
```
* Compara el ID que se quiere eliminar (`$id`) con el ID del usuario que tiene la sesión abierta actualmente (`$_SESSION["id_usuario"]`).
* Si coinciden, bloquea la acción y muestra un aviso amarillo (`warning`): *"No podés eliminar tu propio usuario mientras estás conectado."* Esto evita que un administrador borre accidentalmente su propia cuenta y quede atrapado sin acceso.

#### Regla de Seguridad 2: Borrado Protegido por Integridad Referencial
```php
        try {
            $stmt = $conexion->prepare("DELETE FROM usuarios WHERE id_usuario = ?");
            $stmt->execute([$id]);
            $mensaje = "Usuario eliminado correctamente.";
            $tipo_alerta = "success";
        } catch (PDOException $e) {
            $mensaje = "No se puede eliminar el usuario porque tiene ventas registradas.";
            $tipo_alerta = "danger";
        }
    }
}
```
* **`try { ... } catch (PDOException $e) { ... }`**:
  * Si el usuario a eliminar no es el actual, intenta borrarlo de la tabla `usuarios`.
  * La tabla `ventas` tiene una clave foránea que guarda qué usuario atendió cada venta (`id_usuario`).
  * Si el empleado ya realizó ventas, MySQL bloquea el borrado para no dejar ventas huérfanas sin autor.
  * El bloque `catch` atrapa esa restricción y emite el mensaje en rojo (`danger`): *"No se puede eliminar el usuario porque tiene ventas registradas."*
  * Si no tiene ventas, se elimina correctamente y se emite el mensaje verde (`success`).

### 4. Carga de Datos para Edición (`GET["editar"]`)
Se ejecuta cuando se hace clic en el botón amarillo "Editar" de alguna fila (por ejemplo: `usuarios.php?editar=2`).

```php
if (isset($_GET["editar"])) {
    $id_editar = intval($_GET["editar"]);
    $stmt = $conexion->prepare("SELECT id_usuario, nombre, usuario FROM usuarios WHERE id_usuario = ?");
    $stmt->execute([$id_editar]);
    if ($fila = $stmt->fetch()) {
        $nombre_editar = $fila["nombre"];
        $usuario_editar = $fila["usuario"];
    }
}
```
* Sanitiza el ID con `intval()`.
* **`SELECT id_usuario, nombre, usuario...`**: Nótese que **no se selecciona la contraseña** de la base de datos. Por buenas prácticas de seguridad, las contraseñas encriptadas jamás deben enviarse de vuelta al formulario ni a la vista.
* Extrae el `nombre` y el `usuario` y los almacena en `$nombre_editar` y `$usuario_editar` para rellenar los campos de la pantalla.

### 5. Procesamiento del Formulario: Crear o Actualizar (`POST`)
Se ejecuta cuando el usuario presiona el botón principal del formulario para enviar datos.

```php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $id_usuario = $_POST["id_usuario"] ?? "";
    $nombre = trim($_POST["nombre"] ?? "");
    $usuario = trim($_POST["usuario"] ?? "");
    $password = $_POST["password"] ?? "";
```
* **`$_SERVER["REQUEST_METHOD"] == "POST"`**: Comprueba que la petición sea de tipo POST.
* **`$id_usuario`**: Rescata el ID del campo oculto. Si está vacío, se creará un usuario; si tiene un ID, se modificará.
* **`trim(...)`**: Remueve espacios en blanco accidentales de los extremos en el nombre y usuario.
* **`$password`**: Captura la contraseña escrita (a la contraseña no se le aplica `trim` por si intencionalmente contiene espacios).

#### Validación Condicional de Campos
```php
    if ($nombre == "" || $usuario == "" || ($id_usuario == "" && $password == "")) {
        $mensaje = "Completá todos los campos obligatorios.";
        $tipo_alerta = "danger";
    } else {
```
* **Regla lógica:**
  * El `nombre` no puede estar vacío.
  * El `usuario` no puede estar vacío.
  * **`($id_usuario == "" && $password == "")`**: Si es un usuario nuevo (`$id_usuario == ""`), la contraseña **es obligatoria**. Pero si estamos editando un usuario existente, la contraseña **puede quedar en blanco** si no se desea modificar.
* Si no se cumple esta condición, emite una advertencia en rojo (`danger`).

#### Encriptación y Guardado en Base de Datos
```php
        try {
            if ($id_usuario == "") {
                $password_hash = password_hash($password, PASSWORD_DEFAULT);
                $stmt = $conexion->prepare("INSERT INTO usuarios (nombre, usuario, password) VALUES (?, ?, ?)");
                $stmt->execute([$nombre, $usuario, $password_hash]);
                $mensaje = "Usuario agregado correctamente.";
            } else {
```
* **Caso 1: Creación de Usuario (`$id_usuario == ""`):**
  * **`password_hash($password, PASSWORD_DEFAULT)`**: Encripta la contraseña utilizando un algoritmo criptográfico robusto (`bcrypt`). La contraseña real nunca se almacena en texto plano en la base de datos.
  * Inserta el nuevo registro en la tabla `usuarios` y emite el mensaje de éxito.

```php
                if ($password != "") {
                    $password_hash = password_hash($password, PASSWORD_DEFAULT);
                    $stmt = $conexion->prepare("UPDATE usuarios SET nombre = ?, usuario = ?, password = ? WHERE id_usuario = ?");
                    $stmt->execute([$nombre, $usuario, $password_hash, $id_usuario]);
                } else {
                    $stmt = $conexion->prepare("UPDATE usuarios SET nombre = ?, usuario = ? WHERE id_usuario = ?");
                    $stmt->execute([$nombre, $usuario, $id_usuario]);
                }
                $mensaje = "Usuario actualizado correctamente.";
            }
            $tipo_alerta = "success";
        } catch (PDOException $e) {
            $mensaje = "Error: ese nombre de usuario ya existe.";
            $tipo_alerta = "danger";
        }
    }
}
```
* **Caso 2: Edición de Usuario (`else`):**
  * **Si se escribió una nueva clave (`$password != ""`):** Encripta la nueva contraseña y actualiza el nombre, el usuario y la clave en la base de datos.
  * **Si se dejó la clave en blanco (`else`):** Actualiza únicamente el nombre y el usuario, dejando intacta la contraseña que ya tenía guardada en la base de datos.
* **Control de Usuarios Duplicados (`catch (PDOException $e)`):**
  * Si la columna `usuario` está configurada como única (`UNIQUE`) en la base de datos e intentamos registrar o cambiar a un nombre de usuario que ya pertenece a otra persona, MySQL lanza un error de clave duplicada.
  * El bloque `catch` atrapa ese error e informa amablemente: *"Error: ese nombre de usuario ya existe."* en color rojo.

### 6. Consulta para Listar los Usuarios
```php
$usuarios = $conexion->query("SELECT id_usuario, nombre, usuario FROM usuarios ORDER BY id_usuario DESC")->fetchAll();
```
* Realiza una consulta directa a la tabla `usuarios`.
* Solo selecciona `id_usuario`, `nombre` y `usuario` (nunca el hash de la contraseña).
* **`ORDER BY id_usuario DESC`**: Ordena de mayor a menor para que el usuario más nuevo aparezca primero.
* **`fetchAll()`**: Guarda todas las filas en el arreglo `$usuarios`.

### 5. Columna Izquierda: Formulario Dinámico (`col-md-4`)
Ocupa 4 columnas de 12 en pantallas medianas o grandes (un tercio del ancho total).

```html
            <div class="col-md-4 mb-4">
                <div class="card shadow-sm">
                    <div class="card-header bg-primary text-white">
                        <?php echo ($id_editar != "") ? "Editar Usuario" : "Nuevo Usuario"; ?>
                    </div>
```
* **`card shadow-sm`**: Tarjeta con sombra suave.
* **Cabecera Dinámica:** Si `$id_editar` tiene un valor, muestra *"Editar Usuario"*; si no, muestra *"Nuevo Usuario"*.

#### Campos del Formulario
```html
                    <div class="card-body">
                        <form method="POST" action="usuarios.php">
                            <input type="hidden" name="id_usuario" value="<?php echo $id_editar; ?>">
```
* **`action="usuarios.php"`**: Envía los datos por POST a este mismo archivo.
* **`<input type="hidden" name="id_usuario"...>`**: Campo oculto indispensable que guarda el ID al editar o queda en blanco al crear.

```php
                            <div class="mb-3">
                                <label class="form-label">Nombre Completo</label>
                                <input type="text" name="nombre" class="form-control" required
                                       value="<?php echo htmlspecialchars($nombre_editar); ?>">
                            </div>
                            <div class="mb-3">
                                <label class="form-label">Usuario (para login)</label>
                                <input type="text" name="usuario" class="form-control" required
                                       value="<?php echo htmlspecialchars($usuario_editar); ?>">
                            </div>
```
* **Nombre Completo (`name="nombre"`):** Obligatorio (`required`). Precarga `$nombre_editar` al editar.
* **Usuario (`name="usuario"`):** Identificador para iniciar sesión. Obligatorio (`required`). Precarga `$usuario_editar`.
* **`htmlspecialchars(...)`**: Protege los textos precargados contra vulnerabilidades XSS.

#### Campo de Contraseña Adaptativo
```php
                            <div class="mb-3">
                                <label class="form-label">Contraseña</label>
                                <input type="password" name="password" class="form-control"
                                       <?php echo ($id_editar == "") ? "required" : ""; ?>>
                                <?php if ($id_editar != ""): ?>
                                    <div class="form-text">Dejala vacía si no querés cambiarla.</div>
                                <?php endif; ?>
                            </div>
```
* **`type="password"`**: Oculta los caracteres escritos mostrando puntos o asteriscos.
* **`($id_editar == "") ? "required" : ""`**: Si es un usuario nuevo, el atributo `required` se activa obligando a escribir una contraseña. Si se está editando, `required` no se agrega.
* **Texto de ayuda (`form-text`):** Si se está editando, muestra una pequeña leyenda explicativa: *"Dejala vacía si no querés cambiarla."*.

#### Botones de Acción del Formulario
```php
                            <button type="submit" class="btn btn-primary w-100">
                                <?php echo ($id_editar != "") ? "Guardar Cambios" : "Agregar Usuario"; ?>
                            </button>
                            <?php if ($id_editar != ""): ?>
                                <a href="usuarios.php" class="btn btn-secondary w-100 mt-2">Cancelar</a>
                            <?php endif; ?>
                        </form>
                    </div>
                </div>
            </div>
```
* **Botón Principal (`btn-primary w-100`):** Cambia su texto a *"Guardar Cambios"* si se está editando o *"Agregar Usuario"* si se está creando.
* **Botón Cancelar (`btn-secondary w-100 mt-2`):** Solo visible al editar. Recarga `usuarios.php` sin parámetros para limpiar el formulario y salir del modo de edición.

### 6. Columna Derecha: Tabla de Usuarios (`col-md-8`)
Ocupa 8 columnas de 12 en pantallas medianas o grandes (dos tercios del ancho de pantalla).

```html
            <div class="col-md-8">
                <div class="card shadow-sm">
                    <div class="card-header">Listado de Usuarios</div>
                    <div class="card-body p-0">
                        <table class="table table-striped table-hover mb-0">
                            <thead class="table-dark">
                                <tr>
                                    <th>ID</th>
                                    <th>Nombre</th>
                                    <th>Usuario</th>
                                    <th style="width: 150px;">Acciones</th>
                                </tr>
                            </thead>
```
* **`p-0` y `mb-0`**: Quitan márgenes y rellenos para que la tabla toque perfectamente los bordes de la tarjeta.
* **`table-striped table-hover`**: Aplica colores de fila alternados y resalta la fila donde se posa el mouse.
* **`thead class="table-dark"`**: Cabecera oscura con cuatro columnas: ID, Nombre, Usuario y Acciones (ancho fijo de 150px).

#### Filas de Datos con `foreach`
```php
                            <tbody>
                                <?php foreach ($usuarios as $usu): ?>
                                    <tr>
                                        <td><?php echo $usu["id_usuario"]; ?></td>
                                        <td><?php echo htmlspecialchars($usu["nombre"]); ?></td>
                                        <td><?php echo htmlspecialchars($usu["usuario"]); ?></td>
                                        <td>
                                            <a href="usuarios.php?editar=<?php echo $usu["id_usuario"]; ?>" class="btn btn-warning btn-sm">Editar</a>
                                            <a href="usuarios.php?eliminar=<?php echo $usu["id_usuario"]; ?>" class="btn btn-danger btn-sm"
                                               onclick="return confirm('¿Seguro que querés eliminar este usuario?');">Eliminar</a>
                                        </td>
                                    </tr>
                                <?php endforeach; ?>
                            </tbody>
```
* **`foreach ($usuarios as $usu)`**: Recorre todos los usuarios de la base de datos y crea un renglón `<tr>` por cada uno.
* **`$usu["id_usuario"]`**: Identificador numérico único.
* **`htmlspecialchars($usu["nombre"])`** y **`htmlspecialchars($usu["usuario"])`**: Muestra los textos limpios de caracteres potencialmente peligrosos.
* **Botón Editar (`btn-warning btn-sm`):** Enlace amarillo que recarga la página enviando `?editar=ID` para subir los datos de este usuario al formulario de la izquierda.
* **Botón Eliminar (`btn-danger btn-sm`):** Enlace rojo que llama a la página con `?eliminar=ID`.
  * **`onclick="return confirm('...');"`**: Ventana emergente nativa de confirmación en JavaScript. Si el usuario hace clic en "Cancelar", la petición se interrumpe y la cuenta no se borra.
